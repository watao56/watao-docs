# DeadLink プロダクトレビュー

**レビュー日**: 2026-02-16  
**レビュアー**: シニアエンジニア / PM視点

---

## 総合評価: B-（可能性はあるが課題多い）

コンセプトは明確で筋が良い。しかし、競合が多い市場で$20/月を達成するには、現状の差別化と獲得戦略では不十分。

---

## 1. プロダクトコンセプト

### 良い点
- **課題が明確**: リンク切れがSEOと読者体験を損なうという痛みは実在する
- **即スキャンの導線が秀逸**: 登録前に価値を体験させるのは正しいアプローチ
- **技術ブロガーに刺さる設計**: Hugo, Astro, Zennなど非WordPress対応は差別化要素

### 懸念点
- **ターゲットが狭い**: 「記事50本以上の中堅ブロガー」は日本市場で数千人規模。そのうち月$5を払う人は1-2%
- **痛みの強度**: リンク切れは「あると困る」程度で「今すぐ金を払って解決したい」レベルではない人が多い
- **頻度の問題**: リンク切れは急がないので、年1回手動チェックで済む人も多い

---

## 2. 料金設計

| | 評価 | コメント |
|---|---|---|
| Free | ✅ 適切 | 週1回・1サイトは体験として十分。制限がPro誘導になっている |
| Pro $5/月 | ⚠️ 微妙 | 個人ブロガーにとって年$60は高い。$3/月または$30/年のほうが転換率は上がる |

### 改善案
- **年額プラン追加**: $36/年（月$3相当）で年間コミット割引 → ARR向上
- **$5は法人向け**: 個人は$3、チームは$10/月のような段階設計
- **従量課金の検討**: サイト数やページ数に応じた従量制のほうが公平感がある

---

## 3. 競合分析

### 主要競合

| サービス | 特徴 | 価格 |
|---|---|---|
| **Broken Link Checker** (WordPress plugin) | WP限定、無料 | $0 |
| **Ahrefs Site Audit** | SEO総合ツールの一部 | $99/月〜 |
| **Dead Link Checker** (.org) | 無料Web版 | $0 |
| **Dr. Link Check** | SaaS、定期監視 | $9/月〜 |
| **LinkChecker** (OSS) | CLI、無料 | $0 |
| **Screaming Frog** | デスクトップ、500URL無料 | £199/年 |

### DeadLinkの差別化ポイント
- ✅ 非WordPress対応（Hugo, Astro等）
- ✅ 日本語UIとJPブロガー特化
- ✅ 即スキャン体験（登録不要）
- ❌ 機能面で既存ツールに劣る（修正提案、レポート詳細度など）

### 厳しい現実
- **無料のCLIツールで十分な人が多い**: `linkchecker`コマンド一発で済む
- **Dr. Link Checkが直接競合**: ほぼ同じコンセプトで$9/月、実績あり
- **Ahrefsユーザーは移行しない**: SEOツール込みでリンクチェック機能も使える

---

## 4. ユーザー獲得戦略

### Zenn記事経由
- ✅ 技術ブロガーへのリーチは良い
- ⚠️ バズっても1回のスパイク。継続流入の仕組みがない
- ⚠️ 「作った話」記事は読まれるが、サービス利用には繋がりにくい（読者は技術に興味がある）

### SEO「リンク切れ チェック 無料」
- ✅ 正しい戦略だが、Dead Link Checker(.org)やScreaming Frogが上位を独占
- ⚠️ SEOで勝つには6-12ヶ月かかる

### 不足している戦略
- **Product Hunt**: 海外ユーザー獲得の機会。英語LP必須
- **X/Twitter自動共有**: 「○○.comをスキャンしたら○件リンク切れが見つかりました」→ ユーザーが自発的にシェアする仕組み
- **ブログへの埋め込みバッジ**: 「Checked by DeadLink」バッジ → オーガニック流入
- **アフィリエイト連携**: ブログ系インフルエンサーへの紹介依頼

---

## 5. UX / ユーザーフロー

### 良い点
- LP→即スキャン→結果→CTA の導線は明確
- ミニマルなデザインで迷わない
- GitHub OAuthとMagic Linkの2パスは適切

### 問題点
- **結果ページにシェアボタンがない**: 口コミ素材にならない
- **スキャン中の体験が貧弱**: 「スキャン中…」だけでは30秒が長く感じる。進捗バーやリアルタイムで見つかったリンクを表示すべき
- **Pricingページの「Coming Soon」**: Pro機能が未実装だと課金できない。これが最大のブロッカー
- **フッターのリンクが全てダミー**: 利用規約、プライバシーポリシー、お問い合わせが`#`リンク → 信頼性を損なう
- **ダッシュボードから結果詳細への導線不足**: レポート一覧はあるが、各レポートの詳細（リンク切れ一覧）を見るUIがない

---

## 6. $20/月目標の達成可能性

### 計算
- Pro 4人 × $5 = $20/月
- Stripe手数料（3.6%）を考慮すると、実質4.2人必要

### 必要なファネル
```
即スキャン利用者: 1000人/月
  → 登録: 50人（5%）
  → Pro転換: 4人（8%の転換率）
```

### 評価: **達成可能だが楽ではない**
- 月1000スキャンを得るには、SEO記事かバイラルが必要
- 現状のマーケティング計画では6ヶ月以上かかる見込み
- **最大のリスク: Proプランが未実装**。課金機能がないと$0のまま

---

## 7. リスクと懸念事項

| リスク | 深刻度 | 対策 |
|---|---|---|
| **Proプラン未実装** | 🔴 Critical | Stripe連携を最優先で実装 |
| **無料で十分と感じるユーザーが多い** | 🟠 High | Free制限を厳しく（月1回、50ページに変更検討） |
| **競合の無料ツールに流出** | 🟠 High | UX差別化（結果の見やすさ、修正提案） |
| **クロール先からブロック** | 🟡 Medium | 設計書通りのpolite crawl対応済み |
| **Vercel Hobby制限（関数10秒）** | 🔴 Critical | 大規模サイトはタイムアウトする。Vercel Proか外部Workerが必要 |
| **DynamoDBの無料枠超過** | 🟢 Low | 当面は問題なし |

---

## 8. 改善提案（優先度付き）

### 🔴 Critical（今すぐ）
1. **Stripe連携を実装してPro課金を有効化** — 課金できないサービスは$0のまま
2. **Vercelの関数タイムアウト対応** — Hobby planは10秒制限。即スキャンの`maxDuration = 60`は効かない。Vercel Pro($20/月)が必要 → インフラコスト再計算
3. **利用規約・プライバシーポリシーの作成** — 法的要件かつ信頼性の問題

### 🟠 High（1-2週間以内）
4. **スキャン結果ページにシェアボタン追加** — Twitter/Xでの拡散が最大の獲得チャネル
5. **OGP画像自動生成** — 「example.comでリンク切れ3件検出」のOGPカード → シェア時のインパクト
6. **進捗表示の改善** — リアルタイムでクロール済みページとリンク数を表示
7. **英語対応** — 日本市場だけでは$20/月も厳しい。i18n対応で市場を10倍に

### 🟡 Medium（1ヶ月以内）
8. **年額プラン追加** — $30/年で転換率UP
9. **レポート詳細ページ** — ダッシュボードからリンク切れ一覧を確認可能に
10. **Internet Archive連携** — リンク切れのアーカイブURLを自動提案（大きな差別化要素）
11. **「Checked by DeadLink」バッジ** — ブログフッターに埋め込み → オーガニック流入

### 🟢 Low（将来）
12. **WordPress REST API連携** — WPユーザーも取り込む
13. **チーム機能** — 法人向け拡張
14. **GitHub Actions連携** — CI/CDでリンクチェック → 開発者向け差別化

---

## まとめ

DeadLinkは「即スキャン体験」というフックが良く、技術的にも堅実に作られている。しかし：

1. **課金機能が未実装**という致命的なブロッカーがある
2. **Vercel Hobbyの制限**でまともにスキャンが動かない可能性が高い
3. **競合が多い市場**で、差別化が「日本語UI」と「非WP対応」だけでは弱い

**次にやるべきこと**: Stripe実装 → Vercelプラン確認 → シェア機能 → 英語対応。この順番で$20/月は現実的に達成可能。
