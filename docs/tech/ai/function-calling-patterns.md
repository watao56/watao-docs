# AI Function Calling設計パターン

ツール呼び出し型エージェントを安全に運用するための設計パターンです。

## 1. 契約（Schema）を先に固定する

- ツールごとにJSON Schemaを定義
- `version` フィールドを持たせ、破壊的変更を検知
- 必須項目を最小化し、曖昧な自由入力を減らす

## 2. リトライとタイムアウト

- 読み取り系: 自動リトライ可（指数バックオフ）
- 書き込み系: 原則1回、再実行は明示確認
- ツール別タイムアウトを定義（短すぎ/長すぎを避ける）

## 3. 権限境界を分離する

- `read-only` と `write` を別ツールに分離
- 削除系は追加確認ステップ
- 外部送信系（メール/投稿）は人間確認を必須化

## 4. 監査ログ

最低限この4点を記録:

- 誰が（session/user）
- いつ（timestamp）
- 何を（tool + args要約）
- 結果（成功/失敗 + エラー要約）

## 5. 失敗時のフォールバック

- ツール失敗時は理由をそのまま返す
- 代替手段を提示（手動手順・再試行条件）
- サイレント失敗を禁止

## 運用チェックリスト

- [ ] ツールごとにSchema version管理
- [ ] タイムアウト/再試行ポリシーを明文化
- [ ] read/write分離済み
- [ ] 監査ログが検索可能
- [ ] 失敗時メッセージ標準化
