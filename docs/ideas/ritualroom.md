# 🔥 RitualRoom

## 概要
3〜8人の小さな実行ルームを作り、毎日10分の「開始宣言」と「完了スタンプ」を回すコミュニティSaaS。

## 海外事例分析
- 参考: **Geneva / Partiful / HabitShare**
- 学び: 日本市場では「日本語UI・日本語フォント最適化・低価格サブスク」に余地が大きい
- ローカライズ戦略: 初期は日本語特化、問い合わせ導線をDiscord中心にしてサポートコストを抑える

## ターゲット
副業コミュニティ運営者、勉強会ホスト、オンラインサロンの少人数班

## 料金
- Free / Host $5/月
- 初月は無料トライアル7日でCVRを取りにいく

## ユーザーフロー
1. サインアップ（Google/Discord）
2. 最小入力（素材 or URL or ルーム設定）
3. 10秒〜2分で成果物生成
4. 共有/エクスポート
5. 有料化トリガー（回数制限・高品質出力・履歴保存）

## デザインコンセプト
焚き火UI（連続達成で火が育つ）。共有したくなる進捗ビジュアル。

## アーキテクチャ
Next.js + Supabase Realtime + Discord OAuth + cron reminders

## DB設計
- 主テーブル: users, rooms, rituals, checkins, streaks, invites, webhook_logs
- 監査ログと課金イベントは分離し、障害時の原因追跡を容易にする

## コスト見積もり（月間）
- 固定費ほぼ$0。通知はDiscord/メール無料枠中心。50ルームでも$2未満。
- 想定売上（目標達成ライン）: Host 4人で$20/月

## MVPスコープ（2週間）
ルーム作成、日次チェックイン、連続達成可視化、Discord通知

## マーケ計画
Discordコミュニティ管理者向けテンプレ配布、7日チャレンジ無料開催

## 技術スタック
Next.js, Supabase, Resend, Discord API, Stripe

## リスク
初期アクティブ率不足。対策: 7日テンプレと自動リマインド強化

## 競合分析
Slack/Discordは汎用チャット。RitualRoomは実行継続UXを商品化。

## $20達成シナリオ
- 価格と必要顧客数: **Host 4人で$20/月**
- 1ヶ月目: 無料配布・SNS事例化
- 2ヶ月目: 有料転換3〜5件で$20超え
