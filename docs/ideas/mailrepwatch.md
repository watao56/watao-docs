# 📧 MailRepWatch — メール到達性モニタリングSaaS

## 1. 概要・解決する課題

**なぜ金を払うか（1行）:** 自社ドメインのメールがスパム判定されて顧客に届かない事態を、常時監視で防ぐ。

### 課題の深刻度
- SPF/DKIM/DMARC設定ミス → メールがスパムフォルダ行き → 売上機会損失
- ドメインがブラックリスト入り → 気づかず数日〜数週間メール不達
- 特にフリーランス・中小企業: メールが主要な顧客連絡手段なのにモニタリングしていない
- MXToolboxでの手動チェックは面倒で続かない → 自動化が必要

### なぜ「ないと困る」か
見積書・請求書・契約メールが届かない = 直接的な売上損失。月$5で防げるなら安い。

## 6. コンポーネント詳細

### 6.1 ドメインチェッカー (Lambda)
- **SPFチェック**: DNS TXTレコードからSPF取得、構文検証、include数制限チェック
- **DKIMチェック**: セレクタ推定（google, default, dkim等）でDNS問い合わせ
- **DMARCチェック**: _dmarc.domain.comのTXTレコード、ポリシー評価
- **MXチェック**: MXレコード存在確認、接続テスト
- **ブラックリストチェック**: 50+のDNSBLに対してクエリ（Spamhaus, Barracuda, SORBS等）
- **総合スコア算出**: 各項目のweighted score → A〜F

### 6.2 通知エンジン
- 前回結果と比較 → 差分がある場合のみ通知
- スコアダウン: 即座にアラート
- ブラックリスト登録: 即座にアラート + 解除手順
- 修正ガイド: ドメインレジストラ別（お名前.com、Cloudflare等）

### 6.3 修正ガイドジェネレーター
- 検知した問題に応じて、具体的なDNSレコード設定例を表示
- 例: 「以下のTXTレコードを追加してください: v=spf1 include:_spf.google.com ~all」

## 7. データベース設計 (DynamoDB)

### Users テーブル
```
PK: USER#{user_id}
SK: PROFILE
Attributes:
  - email: string
  - plan: "free" | "pro" | "business"
  - slack_webhook_url: string (optional)
  - stripe_customer_id: string
  - created_at: ISO8601
```

### Domains テーブル
```
PK: USER#{user_id}
SK: DOMAIN#{domain}
Attributes:
  - domain: string
  - last_check: ISO8601
  - current_score: "A" | "B" | "C" | "D" | "F"
  - spf_status: object
  - dkim_status: object
  - dmarc_status: object
  - blacklists: list[string]  // 現在登録されているBL
  - mx_records: list[string]
```

### CheckHistory テーブル
```
PK: DOMAIN#{domain}
SK: CHECK#{timestamp}
Attributes:
  - score: string
  - details: object (全チェック結果)
  - changes: list[string]  // 前回からの変更点

TTL: 90日（Pro）/ 30日（Free）
```

## 12. リスクと対策

| リスク | 深刻度 | 対策 |
|--------|--------|------|
| DNSBL側からのクエリ制限 | Medium | 主要50リストに絞る、クエリ間隔を分散、キャッシュ活用 |
| DKIMセレクタの推定精度 | Medium | 主要プロバイダ（Google, Microsoft, SendGrid等）のセレクタDBを持つ + ユーザー入力許可 |
| 非エンジニアにDNS修正は難しい | High | レジストラ別のスクリーンショット付きガイド作成（上位10レジストラ） |
| 競合（MXToolbox等）の無料ツール | Medium | 手動 vs 自動の差を訴求、通知機能が差別化ポイント |
| Google Postmaster Tools等のGmail依存 | Low | Gmail以外のメールサーバーにも対応する汎用チェック |

## 13. 競合分析・差別化

| 機能 | MailRepWatch | MXToolbox (Free) | MXToolbox (Pro $129/月) | dmarcian ($20/月〜) | PowerDMARC ($8/月〜) |
|------|-------------|-------------------|------------------------|--------------------|--------------------|
| 自動定期チェック | ✅ | ❌ 手動 | ✅ | ✅ DMARC only | ✅ DMARC only |
| SPF/DKIM/DMARC | ✅ 全部 | ✅ 手動 | ✅ | DMARC特化 | DMARC特化 |
| ブラックリスト監視 | ✅ 50+ | ✅ 手動 | ✅ | ❌ | ❌ |
| 修正ガイド | ✅ レジストラ別 | ❌ | 一般的 | ✅ | ✅ |
| Slack通知 | ✅ Pro | ❌ | ❌ | ❌ | ❌ |
| 最低月額 | **$0-$5** | **$0** | **$129** | **$20** | **$8** |

### なぜ勝てるか
1. **オールインワン**: SPF+DKIM+DMARC+ブラックリストを$5で一括監視。dmarcianやPowerDMARCはDMARC特化
2. **MXToolboxの手動 vs 自動**: 「毎日手動チェックする人はいない」→ 自動化の価値
3. **価格**: MXToolbox Pro $129は中小企業に高い。MailRepWatchは$5
4. **非エンジニア向けUI**: MXToolboxはエンジニア向け。MailRepWatchはスコア+ガイドのシンプルUI
