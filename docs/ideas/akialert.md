# 🚨 AkiAlert - 人気施設キャンセル待ち通知サービス

## 概要
人気飲食店・美容院・クリニック等のキャンセル待ち自動監視＋即座通知サービス。手動チェック不要で、空きが出たら10秒以内にLINE/SMS/メール/Slackで即通知。忙しい現代人の「予約が取れない問題」を完全解決。

## ターゲット
### プライマリ
- **激務会社員（25-40歳）**: 人気レストラン・美容院の予約確保
- **子育て世代（30-45歳）**: 小児科・皮膚科等の予約困難クリニック
- **美容意識高い層（20-35歳）**: 話題のエステ・マッサージサロン

### セカンダリ
- グルメ愛好家・デート予定のカップル
- 健康管理意識高いビジネスパーソン
- インフルエンサー・SNS発信者（話題の店舗確保）

### ペイン
- **手動チェックの限界**: 1日何度も予約サイト確認する疲労
- **タイミング逸失**: 空きが出ても数分で埋まる高競争
- **複数サイト監視**: ホットペッパー、一休、Yelp等の分散チェック負荷
- **機会損失ストレス**: 「あと5分早ければ取れたのに」の後悔

### 解決価値
- **時間節約**: 1日3回×5分の手動チェック → 0分（月4.5時間創出）
- **確実性向上**: 空きが出たら即時通知、予約確率3-5倍
- **ストレス軽減**: 常時監視による安心感

## ユーザーフロー
1. **施設登録**: 希望の店舗・日時・人数を指定（30秒）
2. **監視開始**: 10分間隔で自動チェック開始
3. **空き発見**: 予約可能になった瞬間を検知
4. **即時通知**: 10秒以内にLINE/SMS/メール/Slack通知
5. **ワンクリック予約**: 通知から直接予約サイトへ誘導
6. **成功報酬**: 予約完了時のみ通知回数消費

## 競合分析
### 既存サービス
1. **Resy, OpenTable**: 海外主要、国内対応限定
2. **ホットペッパー通知**: 特定店舗のみ、タイミング遅い
3. **予約アラートbot（個人開発）**: 機能限定、単発サイト

### 競合優位性
- **網羅性**: 複数予約サイト横断監視
- **速度**: 10秒以内即時通知（競合は数分～数時間遅延）
- **精度**: AI施設認識で設定ミス防止
- **利便性**: LINE1つで完結、アプリインストール不要

## リスク & 対策
### 技術リスク
1. **Anti-bot対策**: 予約サイトのスクレイピング規制
   - **対策**: Proxy Rotation, User-Agent偽装, 人間的アクセスパターン
2. **IP BAN**: 大量アクセスでのアクセス制限
   - **対策**: 分散Proxy、適切な間隔調整

### 法的リスク
1. **利用規約違反**: 各サイトのスクレイピング禁止条項
   - **対策**: robots.txt準拠、過度でない頻度、公開情報のみ
2. **著作権**: サイトデザインの模倣
   - **対策**: データのみ抽出、UI模倣なし

### ビジネスリスク
1. **サイト仕様変更**: スクレイピング対象サイトの構造変更
   - **対策**: 複数サイト対応、自動復旧機能
2. **利用規模制限**: 大規模時のサーバー負荷
   - **対策**: 段階的インフラ強化、効率的スクレイピング
