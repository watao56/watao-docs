# 🖼️ OGP Gen — ノーコードOGP画像生成API

## 1. 概要・解決する課題

**OGP Gen**は、ブログ記事やWebページのOGP（Open Graph Protocol）画像を**URL一つで自動生成**するAPIサービス。

### なぜ金を払うか

- ブログ記事ごとにOGP画像を**毎回Canvaで作るのが面倒**
- OGP画像がないとSNSシェア時に**クリック率が30-50%低下**する
- プログラマーはデザインが苦手 → テンプレートから自動生成したい
- **「使わないとSNSからの流入が減る」** = 機会損失を防ぐサービス
- 月$3で全記事のOGPが自動化される

## 4. ユーザーフロー

```
1. サインアップ → APIキー発行
2. テンプレート選択（プレビュー画面で確認）
3. OGP画像URL構築:
   https://ogp-gen.com/api/v1/{template}?title=記事タイトル&author=著者名&bg=gradient-blue
```

## 5. システムアーキテクチャ

```
[SNSクローラー / ブラウザ]
        |
  GET /api/v1/{template}?params
        |
[CloudFront CDN (キャッシュ)]
        |（キャッシュミス時）
[Lambda@Edge or Lambda: 画像生成]
        |
[Satori + Resvg: SVG→PNG変換]
        |
[S3: 生成済み画像キャッシュ]

[CloudFront + S3: ダッシュボードSPA]
        |
[API Gateway → Lambda: 管理API]
        |
[DynamoDB: ユーザー・使用量データ]
```

## 6. コンポーネント詳細

### 6.1 画像生成エンジン
- **Satori**（Vercel製）: JSX → SVG変換
- **Resvg-js**: SVG → PNG変換
- Lambda上で実行（Node.js）
- テンプレート: JSXで定義（React-likeの宣言的UI）
- フォント: Noto Sans JP（日本語対応必須）

### 6.2 テンプレート
- **basic**: タイトル+著者+グラデーション背景
- **tech-blog**: コードブロック風デザイン
- **minimal**: シンプルテキスト+アクセントカラー
- **photo-overlay**: 背景画像+タイトルオーバーレイ
- **dark-mode**: ダーク背景+グロー効果

### 6.3 CDN+キャッシュ戦略
- CloudFrontでキャッシュ（TTL: 7日）
- S3に生成済み画像を保存（永続キャッシュ）
- 同一パラメータの2回目以降はS3から即座に返却
- **キャッシュにより実際の生成回数は大幅削減**

### 6.4 使用量カウンター
- DynamoDBでAPI呼び出し回数をカウント
- Free枠超過時は429 Too Many Requestsを返却
- リアルタイムの使用量表示（ダッシュボード）

### 6.5 ダッシュボード
- APIキー管理
- テンプレートプレビュー&カスタマイズ
- 使用量グラフ
- 生成済み画像一覧

## 12. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| Vercel og-image（無料）で十分 | ユーザーが来ない | Vercel以外のホスティング（Hugo, WordPress等）向けに差別化 |
| Lambda cold startで画像生成が遅い | UX低下 | CloudFrontキャッシュで2回目以降は即座、Provisioned Concurrency検討 |
| テンプレートのデザインクオリティ | 「ダサい」と使われない | 有名OGP画像を参考にデザイン、ユーザーフィードバック反映 |
| 日本語フォントのレンダリング問題 | 文字化け | Noto Sans JPをLambdaレイヤーにバンドル |
| CloudFront転送量コスト増大 | 赤字 | 画像をWebP対応で軽量化、Pro以上のみ高解像度 |

## 13. 競合分析・差別化

| サービス | 価格 | 特徴 | 弱点 |
|----------|------|------|------|
| Vercel og-image | 無料（Vercel内） | Vercel公式 | Vercelホスティング必須 |
| Cloudinary | 従量課金 | 汎用画像変換 | OGP特化ではない、設定複雑 |
| imgix | $10/月〜 | CDN型画像処理 | 高額、エンタープライズ向け |
| 手動Canva | 無料 | 自由度高い | 毎回手作業、自動化不可 |

### OGP Genの差別化
- **OGP特化** — テンプレートがOGP用にデザイン済み
- **URL一つで完結** — コード変更不要
- **日本語フォント対応** — Noto Sans JPプリインストール
- **$3/月** — 手動作成の時間コストに対して圧倒的に安い
- **どのホスティングでも使える** — Vercel以外のユーザー向け
