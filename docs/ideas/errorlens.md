# 🚨 ErrorLens - 小規模サイト向けJSエラー収集SaaS

## 概要
小規模サイト・個人開発者向けJavaScriptエラー収集SaaS。Sentryの1/10の価格でscriptタグ1行で導入、エラー集計・通知・トレンド表示。「本番でユーザーが遭遇してるエラーに気づけない」問題を解決する。

## ターゲット
### プライマリ
- 個人開発者（年収100-500万円）
- フリーランスWebエンジニア（10-50万円/月）
- スタートアップ・小規模チーム（1-10名）
- 副業で個人サービス運営中の会社員

### セカンダリ
- 中小企業のWeb担当者
- Webデザイナー（技術的にライトな層）
- WordPressサイト運営者

### ペイン
- **エラー検知の盲目状態**: ユーザーからのクレームで初めてエラーに気づく
- **Sentryは高すぎる**: 月$26～、個人には予算オーバー
- **Google Analyticsでは限界**: JSエラーの詳細が分からない
- **スタックトレース不足**: どこで何が起きたか特定できない

## 料金
- **フリープラン**: 月1,000エラーまで無料
- **スターター**: 月$3（月10,000エラーまで）
- **プロ**: 月$8（月50,000エラーまで、アラート機能）
- **チーム**: 月$15（月200,000エラー、複数プロジェクト）

## ユーザーフロー
1. **サインアップ**: GitHub/Google認証（30秒）
2. **プロジェクト作成**: サイト名・URL入力（1分）
3. **スクリプト埋め込み**: 1行コードをHTML `<head>` に貼付（1分）
4. **エラー監視開始**: リアルタイムでエラー収集開始
5. **通知・分析**: Slack/Discord/メール通知、ダッシュボードで分析

## アーキテクチャ
### フロントエンド
- **Dashboard**: Next.js + TypeScript + Chart.js
- **Client SDK**: Vanilla JavaScript（2KB）

### バックエンド
- **API**: Node.js + Fastify（高速・軽量）
- **DB**: PostgreSQL（エラーデータ、プロジェクト情報、時系列分析）
- **Queue**: In-memory queue（Redis代替、初期段階）
- **Analytics**: PostgreSQL（適切なインデックスで高速化）

### インフラ
- **App**: Railway（$5/月）

- **CDN**: Cloudflare（$0、JavaScript SDK配信）
- **Total**: $30/月（$15削減、67%コストカット）

## DB設計
```sql
-- プロジェクト
projects (
  id, user_id, name, domain, api_key,
  created_at, updated_at
)

-- エラーイベント（ClickHouse）
error_events (
  id, project_id, message, stack, url, line, column,
  user_agent, timestamp, user_id, session_id,
  fingerprint, count
)

-- エラーグループ（PostgreSQL）
error_groups (
  id, project_id, message, fingerprint,
  first_seen, last_seen, count, status,
  assignee_id
)

-- アラート設定
alert_configs (
  id, project_id, type, threshold, webhook_url,
  slack_channel, email, enabled
)
```
