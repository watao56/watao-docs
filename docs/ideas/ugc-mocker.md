# 🛍️ UGC Mocker

## 概要
商品画像1枚から、SNS広告っぽい「UGC風モック画像」を10秒で作る小粒SaaS。

## 海外事例分析
- 参考: **Arcads / Insense / Billo**
- 学び: 日本市場では「日本語UI・日本語フォント最適化・低価格サブスク」に余地が大きい
- ローカライズ戦略: 初期は日本語特化、問い合わせ導線をDiscord中心にしてサポートコストを抑える

## ターゲット
Shopify小規模店、BASE運営、広告予算が小さいD2C

## 料金
- Starter $9/月
- 初月は無料トライアル7日でCVRを取りにいく

## ユーザーフロー
1. サインアップ（Google/Discord）
2. 最小入力（素材 or URL or ルーム設定）
3. 10秒〜2分で成果物生成
4. 共有/エクスポート
5. 有料化トリガー（回数制限・高品質出力・履歴保存）

## デザインコンセプト
テンプレートは縦動画サムネ風。日本語フォント最適化済み。

## アーキテクチャ
Next.js + Replicate(画像系低コストモデル) + Supabase + S3互換ストレージ

## DB設計
- 主テーブル: users, products, mock_jobs, templates, outputs, subscriptions
- 監査ログと課金イベントは分離し、障害時の原因追跡を容易にする

## コスト見積もり（月間）
- 1生成あたり$0.015前後。月200生成でも約$3。
- 想定売上（目標達成ライン）: 3ユーザーで$27/月

## MVPスコープ（2週間）
商品画像アップロード、テンプレ選択、3パターン出力、透かし/DL

## マーケ計画
Shopifyコミュニティで無料20生成配布、事例LPを先行公開

## 技術スタック
Next.js, Supabase, Replicate, sharp, Stripe

## リスク
生成品質のブレ。対策: テンプレ固定と手動微調整UI

## 競合分析
Canvaは手作業、Arcadsは動画寄り。UGC Mockerは画像特化で即納。
