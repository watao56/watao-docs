# 🤝 SkillSwap 15

## 概要
15分の超短時間で「教える/教わる」を交換するマイクロコミュニティ。英語圏で流行するpeer-learning文化を、日本語の短時間・低心理負担UXで実装。

## 海外事例分析
- **Lunchclub / Polywork** のマッチング文化
- **Focusmate** の短時間セッション定着
- 日本では「雑談会」は多いが、**15分スキル交換に最適化**したSaaSは少ない。

## ターゲット
- 副業層、学生、若手PM/デザイナー
- 「相談したいが1時間は重い」層

## 料金
- Free: 月4マッチ
- Plus: **$6/月**（無制限 + 録画メモ）

## ユーザーフロー
1. 教えられること/学びたいことを3タグ登録
2. 毎朝AIが15分マッチ提案
3. セッション後に相互メモ交換
4. 実績カードをプロフィールに蓄積

## デザインコンセプト
- ポップなカードUI（交換カードの収集感）
- プロフィールがゲーム実績画面のように成長

## アーキテクチャ
- Next.js + Supabase Realtime
- Matching: Cloud Run + ベクトル類似検索（pgvector）
- 通話: Daily.co無料枠から開始

## DB設計
- users, skills_have, skills_want, matches, sessions, notes, reputation

## コスト見積もり（月）
- Hosting/DB: $0〜$3
- 通話API: $5
- AIマッチング: $2
- 合計: **$7〜$10**

## MVPスコープ
- タグ登録
- 1日1回マッチ提案
- 15分通話ルーム
- セッションメモ

## マーケ計画
- 「#15分で学んだこと」投稿テンプレ配布
- コミュニティ運営者へ無料導入

## 技術スタック
Next.js, Supabase, pgvector, Cloud Run, Daily, Stripe

## リスク
- マッチ品質不足による離脱
- 対策: 手動再マッチ・ブロック機能・タグ辞書最適化

## 競合分析
- Focusmate: 作業伴走に強い、学習交換は弱い
- ココナラ: 取引型で重い
- 差別化: 即時・軽量・継続実績化
