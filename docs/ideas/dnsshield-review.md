# 🛡️ DnsShield — シニアエンジニアレビュー

## レビュアー: シニアセキュリティエンジニア（インフラ/DNS専門 11年）

---

## 総合評価: A

**「ドメインハイジャック」「DNS設定ミス」「ドメイン期限切れ」は全て実害が甚大で、かつ防ぎやすい。監視+通知だけでこれだけの価値を提供できるのは優秀。技術的にも極めてシンプル。**

---

## カテゴリ別評価

### 課題の深刻度: A+
- ドメイン失効 → ブランド毀損、フィッシングに悪用される可能性
- DNSハイジャック → 全トラフィックが攻撃者に流れる。最悪のセキュリティインシデント
- NS変更の見落とし → メール不達、サイトダウン
- **「ないと困る」度: 極めて高い。1回のインシデントで数十万円の損害**

### ターゲット精度: A
- Web制作会社がクライアントのドメインを管理するケースは非常に多い
- 「誰が管理してるか曖昧」なドメインが最も危険 → まさにこのツールが必要
- SaaS運営者も自社ドメインのセキュリティは必須

### 料金設計: A
- $5/月で30ドメインは破格
- 1回のドメイン失効防止で数年分のROI
- Agency $12で100ドメインは制作会社に刺さる

### 技術的実現性: A+
- Node.js `dns.resolve()` だけで実装可能。外部APIほぼ不要
- WHOISも標準ライブラリで取得可能
- **最もシンプルなアーキテクチャの案件**。2週間は余裕

### ユニットエコノミクス: A+
- 粗利97.8%
- インフラ$0.20/月はほぼゼロ
- WHOISはNode.jsで直接取得すれば外部API不要

### 差別化: A-
- エンタープライズ向け（SecurityTrails $50+）との価格差が圧倒的
- Uptime Robotとは別レイヤー（DNS変更 vs 死活監視）
- **懸念**: Cloudflareがドメイン管理に無料監視機能を追加する可能性（低い）

### $20達成の現実性: A
- Pro 4人で$20は現実的
- ドメインハイジャック事件のニュースは定期的にバズる → マーケチャンス

### リスク管理: A
- CDN IPローテーションの偽陽性対策が的確
- 複数リゾルバ並列は正しいアプローチ

## 改善提案

1. **SSL証明書の期限も監視**: DNS + SSL + WHOISの3点セットで「ドメインセキュリティ完全監視」に
2. **Slack bot `/dns example.com`**: 即座にDNSレコード一覧を返す → デバッグツールとしても使える
3. **月次セキュリティレポート**: クライアントへの「ドメインセキュリティレポート」PDFを自動生成 → 制作会社の付加価値

## 結論

**A評価。即実行推奨。** DNS/WHOIS監視は技術的に最もシンプルでありながら、防げるリスクが甚大。4人の有料ユーザーで$20達成は容易。セキュリティ意識の高まりと共に需要は増加する一方。
