# 🎲 MicroQuest Dice

## 概要
タスク管理を「サイコロ式クエスト」に変換する**超軽量パーソナル生産性ツール**。先延ばし時に次アクションを自動で最小化する。

## 海外事例分析
- **Goblin Tools**: タスク分解の需要が高い
- **Habitica**: ゲーミフィケーションは継続率を押し上げる
- 日本市場では「RPG調だが大人向けミニマル」領域が空いている

## ターゲット
- ADHD傾向/先延ばしに悩む個人
- 副業ワーカー

## 料金
- Free: 1プロジェクト
- Plus: $4/月（無制限・統計）
- Goal: 5人で$20

## ユーザーフロー
1. やることを1行入力
2. AIが3分タスクに分解
3. サイコロで次行動を提示
4. 完了で連勝カウント可視化

## デザインコンセプト
- ドット絵×ミニマル
- 1画面で開始→完了まで完結

## アーキテクチャ
- PWA (Next.js)
- ローカル優先 + Supabase同期
- AI分解はOpenAI mini

## DB設計
- users(id, plan)
- quests(id, user_id, title, status)
- steps(id, quest_id, text, est_minutes)
- streaks(id, user_id, current, best)

- 合計: $1〜$3
