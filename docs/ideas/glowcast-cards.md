# ✨ GlowCast Cards

## 概要
YouTube/ポッドキャスト動画を、SNSで映える「雑誌風ハイライトカード」に自動変換するツール。

## 海外事例分析
- 参考: **OpusClip / Captions / Canva Docs to Decks**
- 学び: 日本市場では「日本語UI・日本語フォント最適化・低価格サブスク」に余地が大きい
- ローカライズ戦略: 初期は日本語特化、問い合わせ導線をDiscord中心にしてサポートコストを抑える

## ターゲット
個人クリエイター、ポッドキャスター、小規模D2C運営

## 料金
- Free / Pro $6/月
- 初月は無料トライアル7日でCVRを取りにいく

## ユーザーフロー
1. サインアップ（Google/Discord）
2. 最小入力（素材 or URL or ルーム設定）
3. 10秒〜2分で成果物生成
4. 共有/エクスポート
5. 有料化トリガー（回数制限・高品質出力・履歴保存）

## デザインコンセプト
グラデーション背景＋紙面風タイポ。1クリックで「見せたくなる」サムネ生成。

## アーキテクチャ
Next.js + Cloudflare R2 + Supabase + ffmpeg + OpenAI mini

## DB設計
- 主テーブル: users, projects, clips, card_styles, exports, billing_events
- 監査ログと課金イベントは分離し、障害時の原因追跡を容易にする

## コスト見積もり（月間）
- 固定費: Vercel/Cloudflare無料枠 + Supabase $0〜$5。変動費: 10分動画でAI+処理 $0.03程度。
- 想定売上（目標達成ライン）: Pro 4人で$24/月

## MVPスコープ（2週間）
URL投入→ハイライト抽出→3枚カード生成→PNG書き出し

## マーケ計画
Xで「ビフォー/アフター」投稿テンプレ配布、音声配信者コミュニティへ無料枠提供

## 技術スタック
Next.js, Supabase, ffmpeg, OpenAI gpt-4o-mini, Stripe

## リスク
長尺動画処理の待ち時間。対策: 10分上限＋ジョブキュー

## 競合分析
Canvaは汎用、OpusClipは動画中心。GlowCastは「静止カード特化」で差別化。

- 1ヶ月目: 無料配布・SNS事例化
- 2ヶ月目: 有料転換3〜5件で$20超え
