# ⚡ EnergyLane

## 概要
「今のエネルギー（高・中・低）」を1タップ入力すると、ToDoを体力に合わせて自動並び替え。燃え尽き防止に特化した個人向け生産性ツール。

## 海外事例分析
- 参考サービス: **Rise Calendar energy planning / Stoic / Sunsama**
- 海外では「短時間で見栄えの良い成果物を作る」需要が強い。日本市場では日本語UI・日本語テンプレ不足が参入余地。

## ターゲット
副業ワーカー、在宅フリーランス、ADHD傾向ユーザー

## 料金
Free: 3リストまで / Pro $5/月（無制限+週次分析）

## ユーザーフロー
(1)タスク登録→(2)必要エネルギー設定→(3)現在の体力入力→(4)実行順提示→(5)終了後ログ

## デザインコンセプト
心拍UIをモチーフにした柔らかい配色。プレッシャーを感じない。

## アーキテクチャ
PWA (Next.js) + Supabase + Local-first cache + optional Notion連携

## DB設計（MVP）
- users, tasks, energy_logs, sessions, weekly_insights, subscriptions

## コスト見積もり（月次）
AIは週次コメント生成のみ。月間1ユーザー$0.03以下。ほぼ固定費ゼロ。

## MVPスコープ（2週間）
エネルギー入力、ソート、実行ログ、週次レポート、課金

## マーケ計画
「やる気がない日専用ToDo」訴求でTikTok/Threads短尺投稿。

## 技術スタック
Next.js PWA, Supabase, Stripe, OpenAI mini

## リスク
継続率低下→連続利用バッジより「休めた日」の可視化を入れて罪悪感を減らす。

## 競合分析
一般ToDoは時間軸中心。EnergyLaneは体力軸で差別化。
