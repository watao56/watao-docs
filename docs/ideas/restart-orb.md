# 🔮 RestartOrb

## 概要
🔮 RestartOrbは、パーソナルツール/生産性（中断復帰を1タップ化）を狙う月$20到達向けの超小型プロダクト。

## 海外事例分析
- 参照トレンド: Goblin Tools / Sunsama / Reclaim AI
- 示唆: 海外では「短時間で成果が出る」「見た目がシェアしやすい」体験が伸びている。
- 日本向け再設計: 導入ハードルを下げ、テンプレ主導で初回価値を10分以内に提供。

## ターゲット
- マルチタスクで「再開コスト」に悩む個人開発者・学生

## 料金
- $4買い切り + $1.5/月 Syncオプション

## ユーザーフロー
- ブラウザ拡張で作業断片を保存→再開時にAIが3行ブリーフ表示→次アクション実行

## デザインコンセプト
- 球体オーブUIに「次の一手」を大きく表示。迷いを減らすミニマル設計。

## アーキテクチャ
- Chrome Extension + Firebase free tier + lightweight LLM cache

## DB設計
- 主テーブル: users, context_snaps, restart_prompts, devices
- 最小ER方針: usersを親に、課金対象エンティティを1:Nで接続。監査用created_atを全テーブルに付与。

## コスト見積もり（AWS or 無料サービス想定）
- 固定費ほぼ$0、AI要約$0.0008/再開
- AWS移行時: CloudFront + Lambda + DynamoDBでも月$5〜15で運用可能。

## MVPスコープ
- タブ/メモ保存、再開カード、1日サマリー、ローカル優先保存

## マーケ計画
- Product Hunt・Zennで「再開コスト可視化」記事を公開
- 初月KPI: 無料登録30 / 有料転換3〜5。

## 技術スタック
- Plasmo, Firebase, Cloudflare Worker, OpenAI mini

## リスク
- 主リスク: 習慣化しないユーザーの解約
- 対策: テンプレ改善を週次で回し、解約理由を5件単位で反映。

## 競合分析
- タスク管理系は計画中心、RestartOrbは「再開瞬間」特化

## $20達成シナリオ
- 買い切り5本($20)で即達成、またはSync 14人で$21

## ユニットエコノミクス
- 初月ARPU $4, 変動費$0.1, 粗利率97%
- 目安LTV/CAC: 3以上（SNSオーガニック前提）。
