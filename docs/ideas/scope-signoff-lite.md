# 🛡️ ScopeSignoff Lite

## 概要
受託/副業案件の「追加修正」の合意を、チャット文面から1クリックで記録する**軽量合意ログ**。保険型は1件のみ採用。

## 海外事例分析
- **Bonsai / HoneyBook**: 受託管理で追加作業合意の重要性
- **DocuSign Clickwrap**: 軽量同意の普及
- 日本では「正式契約ほど重くない、でも後で揉めない記録」が不足

## ユーザーフロー
1. 変更依頼文を貼る
2. 追加範囲・納期・金額候補を抽出
3. 承認リンクを送付
4. タイムスタンプ付き保存

## デザインコンセプト
契約書より軽い「レシートUI」。心理負荷を最小化。

## アーキテクチャ

- Supabase
- e-signは使わず、トークン付き承認URL
