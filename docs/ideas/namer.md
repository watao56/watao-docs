# 🏷️ Namer — AI命名+ドメイン/SNS空き確認サービス

## 1. 概要・解決する課題

**Namer**は、サービス名・会社名・プロダクト名をAIで100案生成し、同時に**ドメイン空き・SNSアカウント空き**をリアルタイムチェックするサービス。

### なぜ金を払うか

- 名前を考えるのに**何日も悩む**のは非常にリアルな課題
- 思いついた名前の.comが空いていない → また考え直し → 無限ループ
- **「名前+ドメイン+SNSが全部取れる」案をAIが一括で出す** = 数日の時間短縮
- 1回$2で数日分の時間を買える = ROI明確
- 起業・新サービス開始という**お金を使うタイミング**で$2は安い

## 6. コンポーネント詳細

### 6.1 AI命名エンジン
- OpenAI GPT-4o-mini API使用（安価で十分な品質）
- プロンプト: ユーザーの入力（業種、キーワード、雰囲気）から100案生成
- カテゴリ分け: 造語系、略語系、擬音系、英語系、日本語+英語ミックス等
- 1リクエスト = 1 API call（バッチで100案返す）

### 6.2 ドメインチェッカー
- RDAP / WHOIS APIで空き確認
- チェック対象: .com, .io, .dev, .app, .co
- 結果をDynamoDBに24時間キャッシュ（API呼び出し削減）

### 6.3 SNSチェッカー
- X (Twitter): ユーザー名存在チェック API
- Instagram: ユーザー名存在チェック（スクレイピング or API）
- GitHub: API v3で確認

### 6.4 決済
- Stripe Checkout Session（都度課金）
- Webhook受信でアクセス権付与

### 6.5 フロントエンド
- Next.js（SSR/SSG for SEO）
- 結果画面: テーブルで100案 + ドメイン空き（✅❌）+ SNS空き
- ドメイン購入リンク（Namecheap/Google Domains アフィリエイト）

## 12. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| AI生成の名前が微妙 | ユーザー不満 | プロンプトを継続改善、カテゴリ別生成 |
| 無料10案で満足してしまう | 有料転換しない | 無料はドメインチェックなし→「取れるか分からない」不安で課金 |
| SNSチェックAPIの制限/変更 | 機能停止 | フォールバック（チェック不可の場合は表示しない） |
| Namelix等の競合 | ユーザー奪取 | ドメイン+SNS一括チェックが差別化 |
| GPT-4o-miniの料金値上げ | コスト増 | Claude Haiku等に切り替え可能な設計 |
