# 🧭 Decision Dock

## 概要
🧭 Decision Dockは、パーソナルツール/生産性（迷いを3択化）の月$20到達を狙う小粒プロダクト。

## 海外事例分析
- Sunsamaの1日設計思想 / Goblin Toolsの認知負荷軽減
- 海外で成立している行動（短尺投稿/コミュニティ連鎖/軽量自動化）を日本語UXに再設計する。

## ターゲット
意思決定で止まりがちな個人開発者、副業ワーカー、ADHD傾向の人

## 料金
Free（1日3件） / Solo $4/月（無制限） / Coach $9/月（共有レビュー）

## ユーザーフロー
1) 迷っているテーマ入力 2) AIが3択+コスト比較を生成 3) 1つ選んで30分タイマー開始 4) 結果を蓄積

## デザインコンセプト
港のドックをモチーフに、3枚カードが滑り込むUI。選択後は視界から他案を消す。

## アーキテクチャ
Next.js + Supabase + OpenAI Responses API + local notifications

## DB設計
- users, decisions, options, commits, outcomes, streaks

## コスト見積もり
LLMは短文プロンプトのみで1意思決定$0.003程度。月1,000件でも$3前後。

## MVPスコープ
3択生成、30分コミット、結果ログ、週次レポート

## マーケ計画
「TODOではなくDECIDE」を軸にXでビフォー/アフター事例投稿。

## 技術スタック
Next.js, Supabase, OpenAI mini, Trigger.dev, Stripe

## リスク
AI提案の妥当性→根拠欄必須。医療/法務助言を禁止。

## 競合分析
ToDoアプリは選択支援が弱い。ChatGPT単体は履歴構造が弱い。

## $20達成シナリオ
$4プラン5人で$20達成。無料→有料転換10%で母数50人。

## ユニットエコノミクス
ARPU $4.6, 変動費/ユーザー$0.25, 粗利約94%。
