# 🧩 MinuteShelf

## 概要
作業開始前後に「1分だけ」記録すると、AIが週次で自分専用の行動パターンを可視化してくれる。

## 海外事例分析
- 参考: **Reflect / DailyBean / Stoic**
- 学び: 日本市場では「日本語UI・日本語フォント最適化・低価格サブスク」に余地が大きい
- ローカライズ戦略: 初期は日本語特化、問い合わせ導線をDiscord中心にしてサポートコストを抑える

## ターゲット
一人で働く開発者、デザイナー、フリーランサー

## 料金
- Free / Plus $4/月
- 初月は無料トライアル7日でCVRを取りにいく

## ユーザーフロー
1. サインアップ（Google/Discord）
2. 最小入力（素材 or URL or ルーム設定）
3. 10秒〜2分で成果物生成
4. 共有/エクスポート
5. 有料化トリガー（回数制限・高品質出力・履歴保存）

## デザインコンセプト
本棚UI。1日をカードとして積み上げ、達成で棚が育つ。

## アーキテクチャ
PWA (Next.js) + Supabase + edge functions + small LLM batch

## DB設計
- 主テーブル: users, entries, tags, sessions, weekly_summaries, experiments
- 監査ログと課金イベントは分離し、障害時の原因追跡を容易にする

## コスト見積もり（月間）
- AI要約は週1回のみ。1ユーザー/月あたり約$0.05。固定費$0〜$5。
- 想定売上（目標達成ライン）: Plus 5人で$20/月

## MVPスコープ（2週間）
1分ログ入力、タグ分析、週次サマリ、行動実験の提案

## マーケ計画
#buildinpublic向け「今週の棚」画像を自動共有

## 技術スタック
Next.js PWA, Supabase, OpenAI mini, Chart.js, Stripe

## リスク
日次入力が続かない。対策: 超短入力＋未入力時の1タップ再開

## 競合分析
Notion日記は重い。MinuteShelfは1分特化で継続率を取る。
