# 🏢 BizNotify — 法人届出・報告書期限リマインダー

## 概要

法人運営に必要な届出・報告書の提出期限を管理し、準備開始タイミングでアラートを送るサービス。法人税申告だけでなく、**社会保険の算定基礎届（7月）、労働保険の年度更新（6-7月）、36協定の更新（毎年）、定款変更届、役員変更届、消防署への届出**など、忘れると罰金・行政処分のリスクがある提出物を網羅。

**TaxCalendarとの違い**: TaxCalendarはフリーランス個人の税務期限。BizNotifyは法人の税務以外も含む全届出（社保・労務・消防・登記等）を管理。

## ターゲット

- **メイン**: 1-30人規模の中小企業（経理/総務が1人で兼任、顧問税理士/社労士がいない）
- **サブ**: 創業1-3年目のスタートアップ（何を届出すべきか分からない）
- **拡張**: 税理士/社労士事務所（顧問先の管理ツール）

## ユーザーフロー

1. **登録**: メールで登録
2. **会社情報入力**: 法人種別、設立日、決算月、従業員数、業種
3. **自動生成**: 入力情報から該当する届出一覧を自動生成（決算月から逆算）
4. **カスタマイズ**: 不要な項目の除外、独自の期限追加
5. **通知設定**: 通知タイミング（60日前、30日前、7日前）と通知先
6. **アラート受信**: 「36協定の更新期限まであと30日。届出書類と従業員代表の選出が必要です」
7. **チェックリスト**: 各届出に必要な書類・手続きを表示
8. **完了記録**: 提出完了→翌年の期限を自動更新

## アーキテクチャ

```
[ユーザー] → [Next.js SPA] → [API Gateway]
                                    ↓
                              [Lambda: CRUD]
                                    ↓
                              [DynamoDB]
                                    ↓
                          [EventBridge: 毎日 7:00 AM]
                                    ↓
                          [Lambda: 期限チェッカー]
                                    ↓
                          判定: 今日 = 通知日?
                                    ↓ Yes
                          [SES / LINE Notify / Slack]
```

## リスク

| リスク | 影響 | 対策 |
|--------|------|------|
| 法改正によるテンプレート更新 | 誤った期限通知 | 四半期レビュー、官報RSS監視 |
| TaxCalendarとの差別化 | カニバリ | TaxCalendarはフリーランス個人向け。BizNotifyは法人の全届出。明確に分離 |
| 税理士/社労士の抵抗 | 採用阻害 | 「代替」ではなく「補助ツール」として提案。顧問先管理に使える |
| 業種ごとの届出が多すぎる | テンプレート維持 | 共通項目30+業種別10項目に絞る |

## 競合分析

| 競合 | 特徴 | BizNotifyの優位性 |
|------|------|-------------------|
| freee/MF | 会計ソフト（税務期限は一部表示） | 社保・労務・消防は対象外 |
| SmartHR | 労務管理 | $400/月〜。中小には高い |
| Googleカレンダー | 手動登録 | テンプレートなし、チェックリストなし |
| 税理士に相談 | 確実 | 税務のみ。社保・労務は社労士、消防は自分で管理 |
| TaxCalendar（自社） | フリーランス向け税務 | 法人の税務以外（社保、労務、登記、消防）は対象外 |
