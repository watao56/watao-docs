# 🧩 Remix Baton

## 概要
毎週1つのお題に対して、参加者が前の人の作品を**リミックスして“バトン”する**コミュニティSaaS。AIが「どこを変えたか」を可視化し、参加しやすい創作連鎖を作る。

- カテゴリ: ソーシャル/コミュニティ
- 目標: 月$20（$5コミュニティ課金×4人）

## 海外事例分析
- Partiful: 「見た目が楽しい=招待率が上がる」
- Discord創作サーバー文化: 参加障壁は低いが、継続導線が弱い
- Figma Community: Remix文化は強いが、日常SNSとの接続が弱い

示唆: 日本では「お題型」「連鎖型」が強い。**毎週の定例導線**をプロダクト化する価値がある。

## ターゲット
- イラスト/短文/動画の小規模クリエイターコミュニティ
- 学生サークル、ファンコミュ
- Discord運営者

## 料金
- Free: 1ルーム、週1バトン
- Host: $5/月（5ルーム、アーカイブ、投票）
- Guild: $12/月（無制限、ブランド設定、CSV出力）

## ユーザーフロー
1. ルーム作成（テーマ/期間/ルール）
2. 初回作品を投稿
3. 次参加者を自動割当
4. AIが差分コメントを生成
5. 週末にベスト連鎖を共有カード化

## デザインコンセプト
- ネオン色の「回ってくる感じ」アニメーション
- スマホ縦スクロール優先
- 1タップで「次にやること」が分かるUI

## アーキテクチャ
- Next.js + Supabase Realtime
- 画像/動画は Cloudflare R2
- AI差分説明: OpenAI miniモデル
- Discord OAuthログイン

## DB設計
- rooms(id, owner_id, name, rule_text, cadence)
- entries(id, room_id, author_id, parent_entry_id, media_url, text)
- baton_queue(id, room_id, user_id, order_no)
- votes(id, entry_id, user_id, created_at)

## リスク

- 本案: **連鎖参加と差分可視化を標準装備**
