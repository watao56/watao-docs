# 👥 CrewLoop

## 概要
👥 CrewLoopは、ソーシャル/コミュニティ（少人数実行サークル）に特化した月$20目標のマイクロプロダクト。**AIエージェントだけで2週間以内にMVP実装**できるスコープに限定し、初期コストを最小化する。

## 海外事例分析
- 参照トレンド: Caveday / Focusmate / Geneva の「小さなコミュニティ課金」
- 示唆: 日本市場ではローカライズ（日本語UI・国内決済・和文最適化）で差別化余地が大きい。

## ターゲット
- 副業ビルダー、受験生、筋トレ習慣化層

## 料金
- Free / Circle Host $5 / Team $15

## ユーザーフロー
1) 3〜6人のクルー作成 → 2) 週間ゴール宣言 → 3) 毎日1タップ進捗報告 → 4) 自動で週次まとめ画像を共有

## デザインコンセプト
ステッカー風UI、達成時にリボン演出。共有画像が映える設計。

## アーキテクチャ
Next.js + Supabase Realtime + Cron（集計） + Discord/LINE通知

## DB設計（最小）
- users, crews, memberships, daily_checkins, weekly_goals, badges, share_cards

## コスト見積もり（月次）
- 20有料ユーザー時: 約$2.2/月（ほぼDB/帯域のみ）
- AWS/無料枠超過時はCloudflare/Vercel無料枠優先で吸収

## MVPスコープ（2週間）
- クルー作成、チェックイン、連続日数、週次シェアカード、課金
- 認証、決済、利用制限、簡易分析（Mixpanel代替でeventsテーブル）

## マーケ計画（最初の30日）
- Discordコミュニティ5箇所へ無料導入。ホスト向けに「運営負荷0」を訴求。
- LPは1ページ、CTAは1つに絞る

## 技術スタック
- Next.js, Supabase, Vercel, Stripe, Resend

## リスク
- 過疎化→7日無反応で自動リブートメッセージ。荒らし→招待コード制

## 競合分析
- Discordは汎用、Habiticaはゲーム性。CrewLoopは「小グループ運営自動化」に集中

## $20達成シナリオ
- Host $5 ×4人 = $20 MRR
- 目標: 30日以内に達成可能な「少人数有料化」設計

## ユニットエコノミクス
- ARPU $5.4, 変動費/人 $0.05, 粗利 99.1%
- LTV/CACは初期フェーズでLTV>3x CACを最低ライン

## 実装指示（AIエージェント向け）
1. DB migration作成
2. 認証/課金/利用制限
3. コア機能1本を先に完成
4. ログ計測とエラーハンドリング
5. LP公開→初回ユーザー5人獲得
