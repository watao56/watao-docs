# ✍️ CopyTone — AIブランドボイス分析＆ライティングアシスタント

## 概要

企業やクリエイターの「ブランドの声（トーン&マナー）」をAIが学習し、全コンテンツで統一されたトーンを維持するライティングアシスタント。既存テキスト（ブログ、SNS、メール）を分析してブランドボイスプロファイルを自動生成。新しいコンテンツ作成時に「あなたのブランドらしい」文章をAIが提案・チェック。

## 海外事例分析

| サービス | 規模 | 特徴 |
|---------|------|------|
| **Writer.com** | $200M+ 評価 | AI企業向けライティング。$18/人/月〜 |
| **Jasper** | $125M+ ARR | AIコピーライティング。ブランドボイス機能あり |
| **Acrolinx** | $50M+ ARR | エンタープライズ向けコンテンツガバナンス |
| **Hemingway App** | $10K+ MRR | 文章の読みやすさチェック（AI不使用） |

**日本市場の機会**: 日本語のブランドボイス管理ツールは皆無。ChatGPT/Claudeで文章を書いても「AIっぽい」「自社っぽくない」という不満が多い。特に、敬語レベル・カタカナ使用率・文末表現（です/ます vs だ/である）の統一は日本語特有の課題。

## ユーザーフロー

```
1. サインアップ
2. 「ブランドボイス作成」
3. 既存テキストを入力（ブログURL or テキスト貼り付け 5-10本）
4. AI分析 → ブランドボイスプロファイル自動生成
   - トーン（フォーマル↔カジュアル）
   - 感情（温かい↔クール）
   - 敬語レベル（です/ます↔だ/である↔混合）
   - カタカナ語使用度
   - 文の長さ傾向
   - 頻出表現・避ける表現
   - ペルソナ（例:「30代女性マーケター、親しみやすく知的」）
5. プロファイルを微調整
6. 新テキスト入力 → AIが「ブランドらしさスコア」算出
7. 改善提案（例:「この部分はもう少しカジュアルに」）
8. ワンクリックでリライト（ブランドボイスに合わせて調整）
```

## デザインコンセプト

- **"言葉のDNA"**: ブランドボイスを視覚的なレーダーチャートで表現
- テキスト入力画面はNotion風のミニマルエディタ
- リアルタイムでトーンスコアが右サイドバーに表示
- Before/Afterの差分表示（GitのDiff風）
- ブランドカラーをUIに反映（ブランドに寄り添う）

## アーキテクチャ

```
[Webアプリ (Next.js)] → [API (Next.js API Routes)]
                              ↓
                    [AI分析エンジン]
                    ├── テキスト前処理 (形態素解析: kuromoji)
                    ├── ボイス分析 (GPT-4o-mini)
                    ├── トーンスコアリング (GPT-4o-mini)
                    └── リライト (GPT-4o-mini)
                              ↓
                    [Supabase (PostgreSQL)]
```

### コンポーネント
- **フロントエンド**: Next.js 14 + Tailwind CSS + Tiptap (エディタ)
- **AI**: OpenAI GPT-4o-mini（分析・スコアリング・リライト全て）
- **形態素解析**: kuromoji.js（日本語特有の分析）
- **DB/Auth**: Supabase
- **決済**: Stripe
- **Chrome拡張**: Plasmo

## DB設計

```sql
users (
  id UUID PK,
  email TEXT UNIQUE,
  plan TEXT DEFAULT 'free',
  stripe_customer_id TEXT,
  check_count_month INT DEFAULT 0,
  created_at TIMESTAMPTZ
)

brand_voices (
  id UUID PK,
  user_id UUID FK → users,
  name TEXT, -- 「自社ブログ」「クライアントA」
  profile JSONB, -- {
    -- tone: 0.7, -- 0=超フォーマル, 1=超カジュアル
    -- warmth: 0.8, -- 0=クール, 1=温かい
    -- keigo_level: "desu_masu",
    -- katakana_ratio: 0.15,
    -- avg_sentence_length: 45,
    -- persona: "...",
    -- preferred_expressions: [...],
    -- avoided_expressions: [...]
  -- }
  sample_texts TEXT[], -- 学習用テキスト
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
)

checks (
  id UUID PK,
  user_id UUID FK → users,
  brand_voice_id UUID FK → brand_voices,
  input_text TEXT,
  score FLOAT, -- 0-100
  feedback JSONB, -- AIからの改善提案
  rewritten_text TEXT, -- リライト結果
  created_at TIMESTAMPTZ
)
```
