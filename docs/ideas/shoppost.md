# 📱 ShopPost — 小規模店舗向けSNS投稿AI自動生成

> **「なぜ金を払うか」**: SNS投稿が苦手な店舗オーナーが、料理や商品の写真を撮るだけでプロ品質の投稿文を即生成できるため。

## 1. 概要・解決する課題

個人経営のカフェ、美容院、花屋、パン屋——小規模店舗にとってSNS（Instagram、X）は最重要の集客チャネル。しかし店舗オーナーの本業は料理や施術であり、**「何を書けばいいか分からない」「文章を考える時間がない」**が最大の悩み。

結果、投稿が月1-2回に減り、フォロワーが増えず、集客できない悪循環に陥る。

ShopPostは「写真を1枚アップロード → AIが投稿文+ハッシュタグを3パターン生成 → コピペで投稿」のワンステップサービス。

## 4. ユーザーフロー

```
1. サインアップ（Google or メール）
2. 店舗プロフィール設定（業種、雰囲気、ターゲット客層を選択式で）
3. 「投稿を作る」ボタン
   a. 写真をアップロード（スマホから1枚）
   b. 任意でメモ入力（「今日のランチ限定メニュー」等）
4. AIが3パターンの投稿文+ハッシュタグを生成（5秒）
   - パターンA: カジュアル・親しみやすい
   - パターンB: プロフェッショナル・洗練
   - パターンC: ストーリー性・感情訴求
5. 気に入ったパターンを「コピー」ボタンでコピー
6. Instagram/Xに貼り付けて投稿
```

### AI生成プロンプト設計
```
あなたはSNSマーケティングの専門家です。
以下の店舗情報と写真の説明に基づいて、
Instagram投稿文を3パターン生成してください。

店舗情報:
- 業種: {category}
- 雰囲気: {atmosphere}
- ターゲット客層: {target_audience}

（写真のVision分析結果も利用）

各パターン:
A: カジュアルで親しみやすいトーン（絵文字多め）
B: プロフェッショナルで洗練されたトーン
C: ストーリー性があり感情に訴えるトーン

各パターンに最適なハッシュタグ10個を付与。
文字数は150-300文字。
```

## 7. データベース設計

```sql
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  shop_name TEXT,
  category TEXT, -- 'cafe' | 'restaurant' | 'beauty' | 'handmade' | 'retail' | 'other'
  atmosphere TEXT, -- 'casual' | 'luxury' | 'cozy' | 'modern'
  target_audience TEXT, -- 'young_women' | 'families' | 'business' | 'all'
  plan TEXT DEFAULT 'free',
  monthly_generations INT DEFAULT 0,
  stripe_customer_id TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE generations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  image_url TEXT,
  user_memo TEXT,
  pattern_a TEXT NOT NULL,
  pattern_b TEXT NOT NULL,
  pattern_c TEXT NOT NULL,
  hashtags_a TEXT[],
  hashtags_b TEXT[],
  hashtags_c TEXT[],
  selected_pattern TEXT, -- 'a' | 'b' | 'c' | null
  ai_cost_usd DECIMAL(6,4),
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_generations_user ON generations(user_id);
CREATE INDEX idx_generations_created ON generations(created_at);
```

| 項目 | 月額コスト | 根拠 |

### AIコスト詳細計算
- GPT-4o-miniの料金: 入力$0.15/1M tokens、出力$0.60/1M tokens
- 1回の生成: 入力~500 tokens + 出力~1,000 tokens = $0.000675/回
- Vision（画像分析）: +$0.001/回程度
- **1回あたり合計: 約$0.002**
- 有料ユーザー10人 × 月30回 = 300回/月 → **$0.60/月**
- 無料ユーザー50人 × 月5回 = 250回/月 → **$0.50/月**
- **合計AIコスト: $1.10/月**

### 粗利計算
- 有料ユーザー10人 × $5/月 = $50/月 収入
- コスト: $1.10 (AI) + $1 (ドメイン) = $2.10/月
- **粗利: $47.90/月（粗利率95.8%）** ✅ 95%以上クリア

## 12. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| AI生成文が不自然 | 利用されない | GPT-4o-miniは日本語品質が高い。プロンプト最適化+ユーザーフィードバックで改善 |
| 「ChatGPTに直接聞けばいい」 | 不要と判断される | 店舗プロフィール事前設定、写真Vision分析、ハッシュタグ最適化など「手間の削減」を訴求 |
| OpenAI API料金値上げ | コスト増 | GPT-4o-miniは最安モデル。代替としてClaude Haikuも検討可 |
| InstagramのAPI制限 | 自動投稿不可 | コピペ運用で十分。API投稿は将来課題 |
| 店舗オーナーのITリテラシー | 登録ハードル | Google1クリック認証。操作ステップ最小化 |

## 13. 競合分析・差別化

| 競合 | 特徴 | ShopPostの勝ち筋 |
|------|------|-------------------|
| ChatGPT直接利用 | 汎用。毎回プロンプト書く必要 | 店舗プロフィール事前設定。写真分析。ワンタップ生成 |
| Canva（投稿テンプレート） | 画像デザイン特化。文章は自分で書く | 文章+ハッシュタグ生成に特化。画像は店舗の写真そのまま使用 |
| SNS運用代行（月3-10万円） | プロが運用 | 99%低コスト。自分の言葉・写真で運用できる |
| Later/Buffer | 投稿スケジューリング。文章生成なし | 文章生成に特化。生成→コピペの簡潔さ |
| AIライティングツール（Jasper等） | 英語圏向け、月$49+ | 日本語特化、月$5、店舗特化UI |
