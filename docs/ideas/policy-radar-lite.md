# 🧾 Policy Radar Lite

## 概要
利用中SaaSやAIツールの利用規約変更を「収益に影響する差分だけ」要約通知する超軽量ツール。

## 海外事例分析
- 参考: **Termly updates / PrivacyHawk / TosDR**
- 学び: 日本市場では「日本語UI・日本語フォント最適化・低価格サブスク」に余地が大きい
- ローカライズ戦略: 初期は日本語特化、問い合わせ導線をDiscord中心にしてサポートコストを抑える

## ターゲット
AI活用する個人事業主、小規模制作会社、運用代行

## 料金
- Free / Pro $7/月
- 初月は無料トライアル7日でCVRを取りにいく

## ユーザーフロー
1. サインアップ（Google/Discord）
2. 最小入力（素材 or URL or ルーム設定）
3. 10秒〜2分で成果物生成
4. 共有/エクスポート
5. 有料化トリガー（回数制限・高品質出力・履歴保存）

## デザインコンセプト
赤黄緑の影響スコアカード。変更点を1画面で判断可能。

## アーキテクチャ
Node crawler + diff + LLM summarize + Supabase + Discord通知

## DB設計
- 主テーブル: users, tracked_services, snapshots, diffs, impact_scores, alerts
- 監査ログと課金イベントは分離し、障害時の原因追跡を容易にする

## コスト見積もり（月間）
- クロール＋差分はほぼ無料。AI要約は変化時のみで月$1未満(小規模)。
- 想定売上（目標達成ライン）: Pro 3人で$21/月

## MVPスコープ（2週間）
URL登録、週次スナップショット、差分要約、重要度アラート

## マーケ計画
生成AIコミュニティに「規約変更事故例」記事を投下

## 技術スタック
Node.js, Playwright, diff-match-patch, OpenAI mini, Supabase

## リスク
誤検知で通知疲れ。対策: 重大変更のみ通知し閾値調整可能に

## 競合分析
汎用法務ツールは高価。Policy Radar Liteは個人向け低価格。

- 1ヶ月目: 無料配布・SNS事例化
- 2ヶ月目: 有料転換3〜5件で$20超え
