# 🛡️ ScopeFreeze Lite

## 概要
🛡️ ScopeFreeze Liteは、保険型（仕様変更の合意漏れ防止）の月$20到達を狙う小粒プロダクト。

## 海外事例分析
- Notion/Linearの変更管理運用、契約トラブル防止SaaSの需要
- 海外で成立している行動（短尺投稿/コミュニティ連鎖/軽量自動化）を日本語UXに再設計する。

## ターゲット
受託開発フリーランス、小規模制作会社

## 料金
Solo $6/月 / Team $12/月

## ユーザーフロー
1) 依頼メッセージを転送 2) AIが「追加仕様候補」を抽出 3) 承認テンプレを自動作成 4) 合意ログを時系列保存

## デザインコンセプト
法務っぽさを減らし、黄色警告タグで「ここ危ない」を視覚化。

## アーキテクチャ
Next.js + Supabase + Gmail/Slack連携 + PDF export

## DB設計
- users, clients, threads, scope_items, approvals, evidence_exports

## コスト見積もり
テキスト処理中心で低コスト。10ユーザーでLLM費$1〜3/月。

## MVPスコープ
メッセージ解析、承認テンプレ、承認履歴、PDF出力

## マーケ計画
「揉める前に1クリック合意」をLPで強調。制作会社コミュニティで紹介獲得。

## 技術スタック
Next.js, Supabase, OpenAI mini, Gmail API, Slack API

## リスク
法的効力の誤認→注意書きと弁護士監修テンプレ。

## 競合分析
Notion手運用は抜け漏れ多い。契約SaaSは重く高価。

## $20達成シナリオ
$6プラン4人で$24。保険型だが対象を受託現場に限定して明確価値。

## ユニットエコノミクス
ARPU $7.5, 変動費/ユーザー$0.4, 粗利約95%。
