# 💰 InvoiceTrack — 請求書入金リマインダー

## 概要
フリーランス・中小企業の「請求書を送ったのに入金がない」問題を解決する。請求書の支払期限を登録し、入金確認日までに未入金なら自動でリマインドメールを送信。催促が苦手な人でも、システムが代わりに丁寧な催促メールを送ってくれる。未回収の売掛金は日本だけで年間数兆円規模。

## ターゲットユーザー
- **フリーランス（デザイナー、エンジニア、ライター）**: 月3-10件の請求書を管理
- **個人事業主**: 少人数で経理も兼務、催促を忘れがち
- **小規模Web制作会社**: 複数クライアントへの請求管理

## ユーザーフロー
1. メールアドレスでサインアップ
2. 請求書情報を入力（取引先名、金額、支払期限、取引先メール）
3. 支払期限の3日前に自分へリマインド通知
4. 支払期限当日：入金確認ボタンを押すか、未入金のまま
5. 未入金の場合：翌日に取引先へ丁寧な催促メールを自動送信
6. 入金確認後：ステータスを「入金済み」に更新
7. ダッシュボードで未入金一覧・入金率を確認

## アーキテクチャ
```
[ユーザー] → [Next.js on Vercel]
                    ↓
            [Supabase (認証/DB)]
                    ↓
    [EventBridge] → [Lambda (日次バッチ)]
                    ↓
        [期限チェック] → [SES (リマインド/催促メール送信)]
                    ↓
            [ダッシュボード表示]
```

## リスクと対策
| リスク | 対策 |
|--------|------|
| 催促メールがスパム判定 | SPF/DKIM設定。ユーザー自身のドメインからの送信オプション |
| 取引先との関係悪化を懸念 | 催促文面を「丁寧・ビジネスライク」に統一。送信前にプレビュー機能 |
| freee/MoneyForwardとの競合 | 会計ソフトは大きすぎる。「催促だけ」に特化した軽量ツールが差別化 |
| 個人情報管理 | 取引先メールの暗号化保存。GDPR対応のデータ削除機能 |

## 競合分析
| サービス | 違い |
|----------|------|
| freee/MoneyForward | 会計ソフト全般。月額$20+。請求書催促は付帯機能で弱い |
| Misoca | 請求書作成がメイン。自動催促機能なし |
| 手動管理（Excel） | 忘れる。催促のタイミングを逃す |

**差別化**: 「請求書催促」だけに特化。会計ソフト不要。登録30秒、自動催促。
