# 📅 SlotAlert - 予約枠空き状況リアルタイム通知サービス

## 概要
美容院・クリニック・サロン等の店舗向けに「キャンセル待ち顧客リスト」管理ツールを提供し、キャンセル発生時に自動で顧客に通知するB2B SaaS。店舗の機会損失を防ぎ、顧客満足度を向上させる。

## AkiAlert→SlotAlertの転換理由
- **スクレイピングリスク回避**: B2B提供で正当なビジネスモデル
- **店舗にとっても価値**: キャンセル＝売上損失を防ぐ
- **持続可能なコスト**: プロキシ不要、通常のSaaS構造
- **法的クリーン**: 店舗との正式契約に基づく

## ターゲット
### プライマリ（B2B）
- **美容院・理髪店**: 指名顧客の多い店舗（売上単価3,000-8,000円）
- **エステ・ネイルサロン**: 予約制で高単価（5,000-15,000円）
- **クリニック**: 皮膚科・歯科等の人気医院
- **マッサージ・整体**: リピート客中心の治療院

### セカンダリ（B2C）
- キャンセル待ち希望の一般顧客（店舗経由でのサービス利用）

### 店舗のペイン
- **キャンセル＝売上損失**: 直前キャンセルで予約枠空き
- **手動連絡の負担**: キャンセル待ち顧客への電話連絡
- **機会損失**: 空き枠を埋められずに終了
- **顧客満足度低下**: 予約が取れない顧客の不満

## 料金（B2B向け）

- **ベーシック**: 月$15（月100通知まで、1店舗）
- **プロ**: 月$35（月500通知、3店舗、分析機能）
- **エンタープライズ**: 月$80（無制限、チェーン店対応）

## ユーザーフロー（店舗側）
1. **店舗登録**: 店舗情報・スタッフアカウント作成（5分）
2. **キャンセル待ちリスト作成**: 顧客情報・希望日時登録（2分/人）
3. **キャンセル発生**: システムで該当時間のキャンセル待ち顧客を抽出
4. **自動通知**: LINE・SMS・メールで顧客に空き枠通知
5. **予約確定**: 顧客からの返信で自動予約確定

## ユーザーフロー（顧客側）
1. **キャンセル待ち登録**: 店舗で希望日時・連絡先登録（1分）
2. **通知受信**: 空きが出たらLINE・SMS等で即座通知
3. **予約確定**: 「予約する」ボタンで即座確定
4. **来店**: 通常通り店舗利用

## 競合分析
### 既存サービス
1. **予約システム**: ホットペッパー、EPARKビューティー（キャンセル待ち機能は限定的）
2. **POS連携**: Airレジ、スクエア（通知機能なし）
3. **顧客管理**: サロンボード（キャンセル待ち特化ではない）

### 差別化
- **キャンセル待ち特化**: この機能に完全特化
- **リアルタイム通知**: 即座の空き枠通知
- **ROI明確**: 埋まった予約＝売上直結で価値実感
- **簡単導入**: 既存システムと併用可能

## リスク
### 技術リスク
- **既存システム連携**: POS・予約システムとの連携複雑性
  - **対策**: Phase 1は手動入力、Phase 2で連携
