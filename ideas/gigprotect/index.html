    🛡️ GigProtect — フリーランス契約書リスク検知¶

    概要¶

    フリーランス・個人事業主が受け取った契約書・発注書をアップロードすると、不利な条項（無制限修正義務、著作権の全譲渡、支払い遅延リスク、損害賠償の上限なし等）をAIが検知し、リスクスコアと修正提案を提示するサービス。弁護士に相談すると1回3-5万円かかるところを月$5で何度でもチェックできる。

    ターゲット¶

    • メイン: フリーランスエンジニア・デザイナー・ライター（年間10-30件の契約）
    • サブ: 副業ワーカー（クラウドソーシング経由の契約が不利なことに気づかない）
    • 拡張: 小規模制作会社（下請け契約のリスク管理）

    料金¶

    プラン 月額 内容
    Free $0 月1回スキャン、基本リスク3項目のみ
    Pro $5/月 月10回スキャン、全リスク項目、修正提案
    Business $15/月 無制限スキャン、テンプレート管理、チーム共有

    ユーザーフロー¶

    1. 登録: メールで登録
    2. アップロード: PDF/Word/画像の契約書をドラッグ&ドロップ
    3. 解析: AIが契約書を解析（30秒〜1分）
    4. レポート: リスクスコア（A〜F）と項目別の評価を表示
    5. 修正提案: 各リスク項目に対する修正文言の提案
    6. 履歴: 過去のスキャン結果を一覧管理

    アーキテクチャ¶

    [ユーザー] → [Next.js SPA] → [API Gateway]
                                    ↓
                              [Lambda: Upload]
                                    ↓
                              [S3: 契約書保存]
                                    ↓
                              [Lambda: 解析]
                              (Textract + Claude API)
                                    ↓
                              [DynamoDB: 結果保存]
                                    ↓
                              [SNS → Email: 完了通知]

    コンポーネント¶

    • Frontend: Next.js（Vercel無料枠）
    • API: AWS Lambda + API Gateway
    • DB: DynamoDB
    • ストレージ: S3（契約書PDF保存、暗号化）
    • OCR: Amazon Textract（画像→テキスト変換）
    • AI解析: Claude API（Haiku — 低コスト高精度）
    • 通知: Amazon SES
    • 認証: NextAuth.js

    リスク¶

    リスク 影響 対策
    法的助言と誤解される 法的リスク 「法的助言ではない」免責明記。弁護士相談を推奨
    AI解析の精度 信頼性低下 弁護士監修のプロンプト。ハルシネーション対策
    契約書の機密性懸念 登録躊躇 S3暗号化、30日自動削除、プライバシーポリシー明記
    Claude API値上げ コスト増 Haiku使用で元々低コスト。代替モデル（Gemini Flash）確保

    競合分析¶

    競合 特徴 GigProtectの優位性
    AI-CON（GVA TECH） 法人向け契約書AI 月額数万円〜。フリーランスには高すぎる
    LegalForce 大企業向け契約管理 月額10万円〜。ターゲットが違う
    ChatGPTに直接聞く 汎用AI 専門プロンプトなし。リスク見落とし多い
    弁護士相談 専門家 1回3-5万円。軽い確認には高すぎる
