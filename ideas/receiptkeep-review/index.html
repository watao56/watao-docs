    📝 ReceiptKeep レビュー¶

    総合評価: D¶

    評価内訳¶

    技術実現性: B¶

    • AWS Textract + Next.js構成は技術的に確立済み
    • PWAアプローチでコスト削減は合理的
    • MVPスコープも適切

    課題解決の明確性: A¶

    • 「確定申告時のレシート地獄」は実在する明確な課題
    • フリーランス・個人事業主の切実なニーズ
    • 既存サービス（freee/MF）が高額すぎる問題を指摘

    競合差別化: B-¶

    • 価格優位性は明確（1/4以下）
    • OCR精度とモバイル特化は差別化要素
    • ただし機能差別化は弱い（既存サービスの機能削減版）

    収益性・ユニットエコノミクス: F¶

    • 致命的問題: 粗利率3%は持続不可能
    • 固定コスト$30/月に対して必要ユーザー5人は脆弱すぎる
    • OCR変動コスト（$0.05/枚）が収益を圧迫

    月$20達成可能性: F¶

    • 数値上は可能だが、粗利3%では1人解約で赤字転落
    • 季節性（確定申告時期）でさらに不安定
    • 持続可能性ゼロ

    根本的問題¶

    1. コスト構造の破綻¶

    ARPU: $8.75/月
固定コスト: $6/user/month  
変動コスト: $2.5/user/month
粗利: $0.25/user/month（3%）
    → 完全にコスト倒れ。ビジネスモデルとして成立しない

    2. OCRコストの過大評価¶

    • AWS Textractが$0.05/枚は高すぎる
    • 月50枚/ユーザーの想定も過大
    • 実際のOCR使用量とコストを再計算すべき

    3. インフラコストの非効率性¶

    • Railway/Vercel Proは個人サービスには過大
    • 5ユーザーで$30/月の固定コストは異常

    4. 価格設定の矛盾¶

    • freeeが高すぎる（月1,980円）から$5にしたが
    • $5でも機能を大幅削減すれば競争力なし
    • 価格vs価値のバランス崩壊

    具体的改善提案¶

    1. コスト構造の抜本改革¶

    • インフラ: Supabase無料枠 → $0/月
    • OCR: Google Vision API → $1.5/1000枚（Textractの1/30）
    • Storage: Cloudinary無料枠 → $0/月
    • 固定コスト: $0-5/月に圧縮

    2. 価格・機能の見直し¶

    • フリープラン: 月5枚
    • ベーシック: 月$3（月30枚）
    • プロ: 月$8（月100枚）
    • 平均ARPU: $4程度に下げてでも利益率を確保

    3. 差別化戦略の強化¶

    • 特化: 「確定申告特化」に徹底フォーカス
    • 自動仕分け: 業種別テンプレート提供
    • 税理士連携: 確定申告代行サービスとの提携

    4. 季節性の克服¶

    • 年払い割引: 確定申告前に年額前払いインセンティブ
    • 月次価値: 月次収支レポート、節税アドバイス
    • リマインド機能: 経費入力忘れ防止通知

    判定¶

    現状のビジネスモデルは完全破綻。抜本的な設計見直しが必要。

    粗利率3%では1人でも解約すれば即赤字、固定コスト回収も不可能。 OCRコストとインフラコストの見積もりが現実的でなく、 ビジネスとして成立しない。

    結論: D評価。設計書の全面改訂が必要。
