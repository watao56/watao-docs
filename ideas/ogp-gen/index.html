    🖼️ OGP Gen — ノーコードOGP画像生成API¶

    1. 概要・解決する課題¶

    OGP Genは、ブログ記事やWebページのOGP（Open Graph Protocol）画像をURL一つで自動生成するAPIサービス。

    なぜ金を払うか¶

    • ブログ記事ごとにOGP画像を毎回Canvaで作るのが面倒
    • OGP画像がないとSNSシェア時にクリック率が30-50%低下する
    • プログラマーはデザインが苦手 → テンプレートから自動生成したい
    • 「使わないとSNSからの流入が減る」 = 機会損失を防ぐサービス
    • 月$3で全記事のOGPが自動化される

    2. ターゲットユーザー¶

    ペルソナA: 技術ブロガー（伊藤、31歳）¶

    • Zenn/個人ブログで週1記事投稿
    • OGP画像は面倒なので設定していない or テキストだけの味気ない画像
    • 「Vercelのog-imageみたいなのを簡単に使いたい」

    ペルソナB: 企業テックブログ担当（渡辺、28歳）¶

    • Hugo/Next.jsで企業ブログ運営
    • デザイナーにOGP画像を依頼するのが毎回面倒
    • APIで自動生成できるなら$5/月は安い

    ペルソナC: 個人開発者（松本、25歳）¶

    • 複数のWebサービスを運営
    • 各ページのOGPを動的に生成したい

    3. 料金プラン¶

    プラン 月額 生成数/月 テンプレート 機能
    Free $0 100枚 3種類 透かしあり
    Pro $3/月 5,000枚 全テンプレート 透かしなし、カスタムフォント
    Business $10/月 50,000枚 上記+カスタムテンプレート API優先、SLA

    4. ユーザーフロー¶

    1. サインアップ → APIキー発行
2. テンプレート選択（プレビュー画面で確認）
3. OGP画像URL構築:
   https://ogp-gen.com/api/v1/{template}?title=記事タイトル&author=著者名&bg=gradient-blue
4. HTMLの<meta property="og:image">にURLを設定
5. SNSでシェアするとOGP画像が自動表示
6. ダッシュボードで生成数・アクセス解析確認

    5. システムアーキテクチャ¶

    [SNSクローラー / ブラウザ]
        |
  GET /api/v1/{template}?params
        |
[CloudFront CDN (キャッシュ)]
        |（キャッシュミス時）
[Lambda@Edge or Lambda: 画像生成]
        |
[Satori + Resvg: SVG→PNG変換]
        |
[S3: 生成済み画像キャッシュ]

[CloudFront + S3: ダッシュボードSPA]
        |
[API Gateway → Lambda: 管理API]
        |
[DynamoDB: ユーザー・使用量データ]

    6. コンポーネント詳細¶

    6.1 画像生成エンジン¶

    • Satori（Vercel製）: JSX → SVG変換
    • Resvg-js: SVG → PNG変換
    • Lambda上で実行（Node.js）
    • テンプレート: JSXで定義（React-likeの宣言的UI）
    • フォント: Noto Sans JP（日本語対応必須）

    6.2 テンプレート¶

    • basic: タイトル+著者+グラデーション背景
    • tech-blog: コードブロック風デザイン
    • minimal: シンプルテキスト+アクセントカラー
    • photo-overlay: 背景画像+タイトルオーバーレイ
    • dark-mode: ダーク背景+グロー効果

    6.3 CDN+キャッシュ戦略¶

    • CloudFrontでキャッシュ（TTL: 7日）
    • S3に生成済み画像を保存（永続キャッシュ）
    • 同一パラメータの2回目以降はS3から即座に返却
    • キャッシュにより実際の生成回数は大幅削減

    6.4 使用量カウンター¶

    • DynamoDBでAPI呼び出し回数をカウント
    • Free枠超過時は429 Too Many Requestsを返却
    • リアルタイムの使用量表示（ダッシュボード）

    6.5 ダッシュボード¶

    • APIキー管理
    • テンプレートプレビュー&カスタマイズ
    • 使用量グラフ
    • 生成済み画像一覧

    7. データベース設計（DynamoDB）¶

    Users テーブル¶

    PK: USER#{userId}
Fields: email, apiKey (unique), plan, createdAt
GSI: apikey-index (PK: apiKey)

    Usage テーブル¶

    PK: USER#{userId}
SK: MONTH#{YYYY-MM}
Fields: generateCount, cacheHitCount

    GeneratedImages テーブル¶

    PK: USER#{userId}
SK: IMG#{hash}  (パラメータハッシュ)
Fields: s3Key, template, params, createdAt
TTL: 90日（Free）/ なし（Pro以上）

    8. インフラ+AIコスト見積もり¶

    想定規模（ローンチ3ヶ月後）¶

    サービス 月額見積もり

    S3（画像保存、100MB程度） $0.10

    DynamoDB $0.30
    API Gateway $0.20
    Route 53 $0.50
    CloudWatch $0.20
    合計 $1.90/月

    AIコスト¶

    • AI不使用（テンプレートベースの画像生成）

    その他¶

    • フォントライセンス: Noto Sans JP（無料、Google Fonts）

    総ランニングコスト: 約$2.90/月

    11. 技術スタック¶

    • 画像生成: Satori + Resvg-js (Node.js Lambda)
    • Frontend: React 18 + Vite + TailwindCSS
    • Backend: Node.js (Lambda)
    • DB: DynamoDB
    • CDN: CloudFront
    • Auth: APIキーベース
    • Infra: AWS CDK
    • CI/CD: GitHub Actions

    12. リスクと対策¶

    リスク 影響 対策
    Vercel og-image（無料）で十分 ユーザーが来ない Vercel以外のホスティング（Hugo, WordPress等）向けに差別化
    Lambda cold startで画像生成が遅い UX低下 CloudFrontキャッシュで2回目以降は即座、Provisioned Concurrency検討
    テンプレートのデザインクオリティ 「ダサい」と使われない 有名OGP画像を参考にデザイン、ユーザーフィードバック反映
    日本語フォントのレンダリング問題 文字化け Noto Sans JPをLambdaレイヤーにバンドル
    CloudFront転送量コスト増大 赤字 画像をWebP対応で軽量化、Pro以上のみ高解像度

    13. 競合分析・差別化¶

    サービス 価格 特徴 弱点
    Vercel og-image 無料（Vercel内） Vercel公式 Vercelホスティング必須
    Cloudinary 従量課金 汎用画像変換 OGP特化ではない、設定複雑
    imgix $10/月〜 CDN型画像処理 高額、エンタープライズ向け
    手動Canva 無料 自由度高い 毎回手作業、自動化不可

    OGP Genの差別化¶

    • OGP特化 — テンプレートがOGP用にデザイン済み
    • URL一つで完結 — コード変更不要
    • 日本語フォント対応 — Noto Sans JPプリインストール
    • $3/月 — 手動作成の時間コストに対して圧倒的に安い
    • どのホスティングでも使える — Vercel以外のユーザー向け
