    🎙️ KoeLink — AI音声メモ → 構造化ノート変換サービス¶

    概要¶

    話すだけでアイデアや考えが整理されたノートに変換される「声のセカンドブレイン」。海外で大ヒット中のAudioPen（$50K+ MRR、Product Hunt #1複数回）の日本語特化版。日本語の音声認識精度と文化的文脈（敬語・ビジネス用語）に最適化し、日本のナレッジワーカー・クリエイター向けに展開。

    海外事例分析¶

    AudioPen（audiopen.ai）¶

    • 創業者: Louis Pereira（ソロ開発者）
    • MRR: $50K+（2025年時点）
    • ユーザー数: 10万人以上
    • Product Hunt: 複数回#1獲得
    • 料金: 無料プラン + $99/年（Premium）
    • 特徴: 音声→AIが構造化テキストに変換、タグ自動付与、トーン調整

    なぜ海外で流行っているか¶

    1. 思考のボトルネック解消: タイピングより話す方が3〜5倍速い
    2. AIの品質向上: GPT-4レベルの要約・構造化が可能に
    3. 移動中のキャプチャ: 散歩中・運転中のアイデアを逃さない
    4. ジャーナリング文化: 海外の「morning pages」「brain dump」文化との親和性
    5. シンプルUX: 録音ボタン1つで完結する体験

    日本で未展開/弱い理由¶

    1. 日本語音声認識の精度問題: AudioPenは英語最適化、日本語はおまけ
    2. 敬語・ビジネス用語の扱い: 「お疲れ様です」等の定型句処理が未対応
    3. 日本語UIの不在: 英語UIのみで心理的ハードル
    4. 文化的背景: 日本人は「話して記録」に慣れていないが、LINEボイスメッセージの普及で変化中
    5. ローカル決済未対応: クレカのみ、コンビニ決済等なし

    参入チャンス¶

    • AudioPenの日本語対応は不十分 → 日本語特化で圧倒的品質差を出せる
    • Whisper large-v3 + GPT-4o-miniで日本語認識精度は実用レベルに到達
    • 日本のフリーランス・副業ワーカー300万人が潜在ターゲット

    ターゲット¶

    メインターゲット¶

    • フリーランス/副業ワーカー（25-45歳）: アイデア整理、議事録、ブログネタ収集
    • クリエイター/ライター: 取材メモ、ネタ帳、原稿の下書き
    • スタートアップ経営者: 移動中のアイデア記録、MTG振り返り

    サブターゲット¶

    • 学生: 講義メモ、レポートの下書き
    • 営業職: 商談メモ、日報作成

    料金¶

    プラン 月額 内容
    Free ¥0 月10回まで、1回3分まで、基本変換
    Pro ¥980/月（年払い¥780/月） 無制限、1回30分、トーン調整、タグ自動付与、エクスポート
    Team ¥1,980/人/月 Pro全機能 + 共有ワークスペース、チーム検索

    ユーザーフロー¶

    1. LP訪問 → 「3秒で試す」ボタン → ログイン不要で即録音体験
2. 録音（マイクボタンタップ → 話す → 停止）
3. AI処理（2-5秒）→ 構造化ノート表示
   - 要約（1行）
   - 構造化テキスト（見出し・箇条書き）
   - タグ自動付与
   - トーン選択（カジュアル/ビジネス/ブログ記事風）
4. 保存 → ダッシュボードに蓄積
5. 検索・フィルタ・エクスポート（Notion/Markdown/テキスト）

    デザインコンセプト¶

    ブランディング¶

    • ブランド名: KoeLink（声 + Link＝繋がり）
    • タグライン: 「声で考える。AIが整える。」
    • ロゴ: 音波のウェーブが文字のラインに変わるモーション
    • カラー: ダークモード基調、アクセントにグラデーション（紫→青）

    UIトーン¶

    • ミニマル・呼吸感: 録音中は画面が脈動するようなアニメーション
    • ダークモード優先: クリエイター好みの洗練されたダーク
    • モバイルファースト: 片手操作で完結するUI
    • マイクロインタラクション: 録音→変換のプロセスが視覚的に美しい

    LP設計¶

    • ヒーロー: 大きな録音ボタン + リアルタイムデモ（音声→テキスト変換アニメーション）
    • ソーシャルプルーフ: 「1000人が声で考え始めた」
    • 3ステップ説明: 話す → AI整理 → 活用
    • 体験CTA: ログイン不要で即試せるデモ

    アーキテクチャ¶

    [ブラウザ/PWA]
    ↓ 音声ファイル（WebM/Opus）
[Cloudflare Workers]
    ↓
[AWS Lambda] → [OpenAI Whisper API] → テキスト化
    ↓
[OpenAI GPT-4o-mini API] → 構造化・要約・タグ付与
    ↓
[Supabase (PostgreSQL + Auth + Storage)]
    ↓
[Next.js on Vercel] ← SSR/ISR

    DB設計¶

    -- ユーザー
users (
  id UUID PK,
  email TEXT UNIQUE,
  plan TEXT DEFAULT 'free',
  usage_count INT DEFAULT 0,
  created_at TIMESTAMPTZ
)

-- 音声メモ
notes (
  id UUID PK,
  user_id UUID FK → users,
  audio_url TEXT,          -- Supabase Storage
  raw_transcript TEXT,     -- Whisper出力
  structured_text TEXT,    -- GPT構造化出力
  summary TEXT,            -- 1行要約
  tone TEXT,               -- casual/business/blog
  tags TEXT[],             -- 自動タグ
  duration_sec INT,
  created_at TIMESTAMPTZ
)

-- エクスポート履歴
exports (
  id UUID PK,
  note_id UUID FK → notes,
  format TEXT,             -- notion/markdown/text
  created_at TIMESTAMPTZ
)

    リスク¶

    リスク 影響 対策
    AudioPenが日本語対応強化 高 日本語品質・ローカルUXで差別化、先行者利益を確保

    無料ユーザーが転換しない 中 Free制限を適切に設定、Proの価値（トーン調整・無制限）を明確化
