    🏷️ Namer — AI命名+ドメイン/SNS空き確認サービス¶

    1. 概要・解決する課題¶

    Namerは、サービス名・会社名・プロダクト名をAIで100案生成し、同時にドメイン空き・SNSアカウント空きをリアルタイムチェックするサービス。

    なぜ金を払うか¶

    • 名前を考えるのに何日も悩むのは非常にリアルな課題
    • 思いついた名前の.comが空いていない → また考え直し → 無限ループ
    • 「名前+ドメイン+SNSが全部取れる」案をAIが一括で出す = 数日の時間短縮
    • 1回$2で数日分の時間を買える = ROI明確
    • 起業・新サービス開始というお金を使うタイミングで$2は安い

    2. ターゲットユーザー¶

    ペルソナA: 個人開発者（中村、29歳）¶

    • 新しいサービスを作るたびに名前で悩む
    • .comドメインが取れる短い名前を探すのに毎回半日以上かかる
    • 「ドメイン取れるかどうか先に知りたい」

    ペルソナB: スタートアップ創業者（高橋、33歳）¶

    • 会社名・サービス名を決める段階
    • 商標チェックまでは求めないが、ドメイン+SNSの空きは一括で知りたい
    • チームで候補をシェアしたい

    ペルソナC: 副業ブロガー（木村、27歳）¶

    • 新しいブログのブランド名を考えている
    • 記事を読んでAI命名に興味を持った

    3. 料金プラン¶

    プラン 価格 内容
    お試し $0 10案生成（ドメインチェックなし）
    1回パック $2 100案生成 + ドメイン(.com/.io/.dev等5TLD) + SNS(X/Instagram/GitHub)チェック
    5回パック $8 上記×5回（$1.6/回）
    月額Pro $5/月 無制限生成 + 全TLDチェック + 商標簡易チェック + チーム共有

    都度課金モデル（サブスクより買い切りが合う利用頻度）

    4. ユーザーフロー¶

    1. LP訪問 → 「何のサービスですか？」にキーワード入力
2. 無料で10案プレビュー表示（ドメインチェックなし）
3. 「もっと見る + ドメインチェック」→ $2支払い（Stripe Checkout）
4. 100案 + 各案のドメイン/SNS空き状況を一覧表示
5. 気に入った案をブックマーク、CSVダウンロード
6. ドメイン購入リンク（アフィリエイト）でそのまま取得可能

    5. システムアーキテクチャ¶

    [CloudFront + S3: SPA/LP]
        |
[API Gateway → Lambda: API]
        |
   ┌────┴────┐
   |         |
[OpenAI API] [ドメインチェックAPI]
   |         |
   └────┬────┘
        |
[DynamoDB: 結果キャッシュ]
        |
[Stripe: 決済]

    6. コンポーネント詳細¶

    6.1 AI命名エンジン¶

    • OpenAI GPT-4o-mini API使用（安価で十分な品質）
    • プロンプト: ユーザーの入力（業種、キーワード、雰囲気）から100案生成
    • カテゴリ分け: 造語系、略語系、擬音系、英語系、日本語+英語ミックス等
    • 1リクエスト = 1 API call（バッチで100案返す）

    6.2 ドメインチェッカー¶

    • RDAP / WHOIS APIで空き確認
    • チェック対象: .com, .io, .dev, .app, .co
    • 結果をDynamoDBに24時間キャッシュ（API呼び出し削減）

    6.3 SNSチェッカー¶

    • X (Twitter): ユーザー名存在チェック API
    • Instagram: ユーザー名存在チェック（スクレイピング or API）
    • GitHub: API v3で確認

    6.4 決済¶

    • Stripe Checkout Session（都度課金）
    • Webhook受信でアクセス権付与

    6.5 フロントエンド¶

    • Next.js（SSR/SSG for SEO）
    • 結果画面: テーブルで100案 + ドメイン空き（✅❌）+ SNS空き
    • ドメイン購入リンク（Namecheap/Google Domains アフィリエイト）

    7. データベース設計（DynamoDB）¶

    Sessions テーブル¶

    PK: SESSION#{sessionId}
Fields: email, keywords, industry, vibe, generatedNames[], paidAt, plan
TTL: 30日

    DomainCache テーブル¶

    PK: DOMAIN#{domainName}
Fields: available (boolean), checkedAt
TTL: 24時間

    Payments テーブル¶

    PK: PAYMENT#{stripeSessionId}
Fields: email, amount, plan, sessionId, createdAt

    8. インフラ+AIコスト見積もり¶

    想定規模（ローンチ3ヶ月後）¶

    • 月間訪問: 500人
    • 無料お試し: 200人
    • $2パック購入: 20人
    • $5月額: 2人

    AWS コスト¶

    サービス 月額見積もり
    Lambda $0.30
    DynamoDB $0.30
    API Gateway $0.20
    S3 + CloudFront $0.50
    Route 53 $0.50
    CloudWatch $0.20
    AWS合計 $2.00/月

    AIコスト（重要）¶

    • GPT-4o-mini: 100案生成 = 約1,000トークン入力 + 3,000トークン出力
    • コスト: 入力$0.15/1M × 1K = $0.00015 + 出力$0.60/1M × 3K = $0.0018
    • 1リクエストあたり約$0.002
    • 月間220リクエスト × $0.002 = $0.44/月

    外部APIコスト¶

    • RDAP/WHOIS: 無料（公開API）
    • Stripe手数料: 3.6% + ¥40/件
    • ドメイン: $12/年 = $1/月

    総ランニングコスト: 約$3.50/月

    10. 周知・マーケティング計画¶

    Phase 1: ローンチ¶

    1. Product Hunt投稿（命名ツールはPHで人気カテゴリ）
    2. Twitter/Xで「サービス名 決まらない」「ドメイン 空いてない」で検索→リプ
    3. Indie Hackers / Reddit r/Entrepreneur に投稿

    Phase 2: コンテンツ¶

    1. 「サービス名の付け方完全ガイド」SEO記事
    2. 「AIに会社名を100個考えてもらった結果」バズ記事
    3. Zenn「個人開発のネーミング術」

    Phase 3: 継続¶

    1. SEO: 「サービス名 ジェネレーター」「会社名 AI」
    2. ドメインアフィリエイト収入（副収入）
    3. 新TLD追加のお知らせでリピート誘導

    ユニークな戦略¶

    • ドメインアフィリエイト: Namecheapアフィリエイトで購入1件あたり$0.5-3の追加収入
    • SEOが強い: 「naming generator」「サービス名 ジェネレーター」は検索ボリューム大

    11. 技術スタック¶

    • Frontend/Backend: Next.js 14 (App Router)
    • AI: OpenAI GPT-4o-mini API
    • DB: DynamoDB
    • Auth: なし（セッションベース、購入時にEmail取得）
    • 決済: Stripe
    • Infra: Vercel（無料枠）or AWS Lambda + S3
    • CI/CD: GitHub Actions

    12. リスクと対策¶

    リスク 影響 対策
    AI生成の名前が微妙 ユーザー不満 プロンプトを継続改善、カテゴリ別生成
    無料10案で満足してしまう 有料転換しない 無料はドメインチェックなし→「取れるか分からない」不安で課金
    SNSチェックAPIの制限/変更 機能停止 フォールバック（チェック不可の場合は表示しない）
    Namelix等の競合 ユーザー奪取 ドメイン+SNS一括チェックが差別化
    GPT-4o-miniの料金値上げ コスト増 Claude Haiku等に切り替え可能な設計

    13. 競合分析・差別化¶

    サービス 価格 特徴 弱点
    Namelix 無料 AIロゴ+名前生成 ドメインチェック弱い、SNS未対応
    Squadhelp $199〜 クラウドソーシング命名 高額、時間かかる
    Lean Domain Search 無料 ドメイン検索 AI生成なし
    ChatGPT直接聞く $20/月 自由度高い ドメイン/SNSチェックは手動

    Namerの差別化¶

    • AIで100案 + ドメイン/SNS一括チェックが1画面で完結
    • $2/回の都度課金 — サブスク不要
    • 日本語対応 — 日本語+英語ミックスの命名も可能
    • ドメイン購入まで一気通貫

    14. $20/月達成の現実的シナリオ¶

    シナリオ¶

    • 月1: Product Hunt投稿 → 10件購入 = $20/月 ✅（初月達成可能）
    • 月2: SEO記事効果 → 15件購入 + Pro 1人 = $35/月
    • 月3: 口コミ + アフィリエイト → 20件 + Pro 2人 + アフィ$5 = $55/月

    根拠¶

    • 都度課金$2は衝動買いしやすい（サブスクのコミットメント不要）
    • 「サービス名 ジェネレーター」の月間検索量: 1,000+（日本語）、10,000+（英語）
    • 起業・新サービス開始は毎日発生するイベント
    • Product Huntの命名ツールカテゴリは注目度高い
    • 10人/月が$2払えば達成 = 非常に現実的
