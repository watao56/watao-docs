    💸 ReceiptKeep - フリーランス向けレシートOCR管理SaaS¶

    概要¶

    フリーランス・個人事業主向けのレシートOCR管理SaaS。スマホで撮影→OCR→自動仕分け→確定申告用CSV/PDF出力。「確定申告時にレシートが見つからない・整理できてない」問題を解決する。

    ターゲット¶

    プライマリ¶

    • フリーランス（月売上10-100万円）
    • 個人事業主（年商100-1,000万円）
    • 小規模事業者（従業員1-5名）

    セカンダリ¶

    • 副業会社員（年間20万円超の所得）
    • 小規模法人の経理担当者

    ペイン¶

    • 確定申告時の地獄: レシート紛失、整理不備で慌てる
    • 経費計算の手間: 手動入力で月末に数時間消費
    • 税務調査への不安: レシート管理がずさんで証拠能力不足
    • freeeやMFクラウドは高すぎる: 月3,000円〜は個人には負担

    料金¶

    • フリープラン: 月5枚まで無料
    • ベーシック: 月$3（月30枚まで）
    • プロ: 月$8（月100枚まで、自動仕分け）
    • 年払い割引: 2ヶ月分無料（確定申告前の囲い込み）

    ユーザーフロー¶

    1. 登録・設定: メール認証、基本情報入力（5分）
    2. レシート撮影: スマホアプリでワンタップ撮影
    3. OCR処理: 自動で金額・店名・日付を抽出（15秒）
    4. 分類・確認: 勘定科目を自動判定、ユーザーが確認・修正
    5. 月次・年次レポート: CSV/PDF出力、確定申告準備

    アーキテクチャ¶

    フロントエンド¶

    • Web: Next.js + TypeScript + Tailwind CSS
    • Mobile: PWA（ネイティブアプリ不要でコスト削減）

    バックエンド¶

    • Full-stack: Next.js API Routes
    • DB: Supabase PostgreSQL（無料枠：500MB、50,000 API calls）
    • Storage: Cloudinary（無料枠：25,000枚/月）
    • OCR: Google Vision API（$1.5/1000枚、初回1,000枚無料）

    インフラ¶

    • App: Vercel Hobby（$0/月）
    • DB: Supabase Free（$0/月、500MB）
    • Storage: Cloudinary Free（$0/月、25GB）
    • OCR: Google Vision API（$1.5/1000枚）
    • Total: $0-3/月（低ボリューム時はほぼ無料）

    DB設計¶

    -- ユーザー
users (
  id, email, name, plan, created_at, updated_at
)

-- レシート
receipts (
  id, user_id, image_url, amount, vendor, date,
  category, description, status, ocr_confidence,
  created_at, updated_at
)

-- カテゴリマスタ
categories (
  id, name, tax_deductible, description
)

-- OCR結果
ocr_results (
  id, receipt_id, raw_text, confidence,
  extracted_amount, extracted_vendor, extracted_date
)

    技術スタック¶

    • Frontend: Next.js 14, TypeScript, Tailwind CSS, React Query
    • Backend: Node.js, Express, Prisma ORM, TypeScript
    • Database: PostgreSQL
    • Storage: AWS S3
    • OCR: AWS Textract
    • Auth: NextAuth.js
    • Deployment: Railway or Vercel
    • Monitoring: Sentry, Mixpanel

    MVPスコープ（2週間）¶

    必須機能¶

    • ユーザー認証（メール認証）
    • レシート画像アップロード
    • OCR処理（AWS Textract連携）
    • 基本的なCRUD（レシート一覧・編集・削除）
    • CSV出力機能
    • 料金プラン管理（Stripe連携）

    スキップ機能¶

    • スマホアプリ（PWAで代用）
    • 高度なカテゴリ自動判定（手動選択）
    • レポート機能（CSVのみ）
    • 複数ユーザー管理

    コスト見積もり¶

    固定コスト（月額）¶

    • App Server: $0（Vercel Hobby）
    • Database: $0（Supabase Free 500MB）
    • Storage: $0（Cloudinary Free 25GB）
    • 合計: $0/月（初期100ユーザーまで）

    変動コスト¶

    • Google Vision OCR: $0.0015/枚（$1.5/1000枚）
    • 月1,000枚処理で$1.5
    • 粗利率: 95%（$3プラン）〜 98%（$8プラン）

    マーケ計画¶

    顧客獲得¶

    1. SEO: 「確定申告 レシート管理」「フリーランス 経費」等でコンテンツマーケティング
    2. SNS: Twitter/Instagram でフリーランス向け税務Tipsを発信
    3. パートナー: 税理士事務所との提携（紹介料10%）
    4. リファラル: ユーザー紹介で1ヶ月無料

    リテンション¶

    • 確定申告時期（1-3月）に使用率急増→年間継続
    • 月次レポート機能で定期的な価値提供
    • 税理士向け連携機能でスイッチングコスト向上

    競合分析¶

    既存サービス¶

    1. freee: 月1,980円〜、高機能だが個人には高額
    2. MFクラウド: 月1,408円〜、同様に高額
    3. やよいの青色申告: 年8,800円、OCR機能は別料金
    4. Receipt: 無料、機能限定、OCR精度低い

    差別化¶

    • 価格: 大手の1/4以下（月$5〜）
    • シンプルさ: レシート管理に特化
    • OCR精度: AWS Textractで高精度
    • モバイルファースト: PWAでアプリ不要

    リスク¶

    技術リスク¶

    • OCR精度: 手書きレシート、小さな文字で精度低下
    • 対策: 信頼度表示、手動修正UI
    • 画像品質: ブレ、影で認識失敗
    • 対策: 撮影ガイド、リトライ機能

    ビジネスリスク¶

    • 季節性: 確定申告時期以外は利用減
    • 対策: 月次レポート、年中使える価値提供
    • 法改正: 電子帳簿保存法等の変更
    • 対策: 法改正対応を差別化要素に

    競合リスク¶

    • 大手参入: freee等が同価格帯を投入
    • 対策: ニッチ特化、サービス品質で差別化

    $20達成シナリオ¶

    想定単価・歩留まり¶

    • ベーシック（$3）: 75%
    • プロ（$8）: 25%
    • 平均単価: $4.25

    必要ユーザー数¶

    • $20 ÷ $4.25 = 4.7人
    • 安全マージン込み: 7人

    獲得計画（確定申告シーズンを狙い撃ち）¶

    • 12月: 3人（SEO「確定申告 レシート」）
    • 1月: 5人（税理士パートナー紹介）
    • 2月: 10人（口コミ、SNS拡散）
    • 3月末: 年払い移行で継続率85%確保

    根拠¶

    • TAM: 日本の個人事業主約300万人
    • SAM: 確定申告でレシート管理に困る層約50万人
    • SOM: 年0.1%獲得で500人（$20達成に十分な余裕）

    ユニットエコノミクス¶

    収益¶

    • ベーシック: $3/月 × 75% = $2.25
    • プロ: $8/月 × 25% = $2.00
    • 合計ARPU: $4.25/月

    コスト（7ユーザー想定）¶

    • 固定コスト: $0/月（無料枠内）
    • 変動コスト: $0.045/user/月（月30枚×$0.0015）
    • 総コスト: $0.045/user/月
    • 粗利: $4.205/user/月（98.9%）

    改善されたポイント¶

    • 粗利率: 3% → 99%に大幅改善
    • 固定コスト: $30 → $0に削減
    • OCRコスト: $0.05/枚 → $0.0015/枚（1/33に削減）
    • 持続可能性: 高い粗利率で安定運営可能
