    💰 InvoiceTrack — 請求書入金リマインダー¶

    概要¶

    フリーランス・中小企業の「請求書を送ったのに入金がない」問題を解決する。請求書の支払期限を登録し、入金確認日までに未入金なら自動でリマインドメールを送信。催促が苦手な人でも、システムが代わりに丁寧な催促メールを送ってくれる。未回収の売掛金は日本だけで年間数兆円規模。

    ターゲットユーザー¶

    • フリーランス（デザイナー、エンジニア、ライター）: 月3-10件の請求書を管理
    • 個人事業主: 少人数で経理も兼務、催促を忘れがち
    • 小規模Web制作会社: 複数クライアントへの請求管理

    料金プラン¶

    プラン 月額 内容
    Free $0 請求書3件/月、手動リマインドのみ
    Pro $4/月 請求書無制限、自動リマインドメール、入金ステータス管理
    Business $9/月 チーム共有、CSV出力、Slack通知、催促テンプレートカスタマイズ

    ユーザーフロー¶

    1. メールアドレスでサインアップ
    2. 請求書情報を入力（取引先名、金額、支払期限、取引先メール）
    3. 支払期限の3日前に自分へリマインド通知
    4. 支払期限当日：入金確認ボタンを押すか、未入金のまま
    5. 未入金の場合：翌日に取引先へ丁寧な催促メールを自動送信
    6. 入金確認後：ステータスを「入金済み」に更新
    7. ダッシュボードで未入金一覧・入金率を確認

    アーキテクチャ¶

    [ユーザー] → [Next.js on Vercel]
                    ↓
            [Supabase (認証/DB)]
                    ↓
    [EventBridge] → [Lambda (日次バッチ)]
                    ↓
        [期限チェック] → [SES (リマインド/催促メール送信)]
                    ↓
            [ダッシュボード表示]

    DB設計¶

    usersテーブル¶

    カラム 型 説明
    id uuid PK
    email varchar ログインメール
    plan enum free/pro/business
    company_name varchar 自社名（メール署名用）

    invoicesテーブル¶

    カラム 型 説明
    id uuid PK
    user_id uuid FK
    client_name varchar 取引先名
    client_email varchar 取引先メール
    amount int 請求金額
    currency varchar 通貨
    due_date date 支払期限
    status enum pending/overdue/paid/cancelled
    paid_at timestamp 入金確認日
    reminder_sent boolean 催促メール送信済みか

    reminder_logsテーブル¶

    カラム 型 説明
    id uuid PK
    invoice_id uuid FK
    sent_at timestamp 送信日時
    type enum self_remind/client_remind
    email_to varchar 送信先

    コスト見積もり¶

    項目 月額
    Vercel (Hobby) $0
    Supabase (Free) $0
    Lambda ~$0.10
    SES (送信) ~$0.50（500通/月）
    EventBridge ~$0.01
    合計 ~$0.61

    AIコスト: なし（AI不使用、テンプレートメール）

    MVPスコープ¶

    • メール認証サインアップ
    • 請求書の登録（取引先名、金額、期限、メールアドレス）
    • 支払期限前の自分へのメール通知
    • 未入金時の取引先への催促メール自動送信（丁寧な定型文）
    • 入金確認ボタン
    • 未入金一覧ダッシュボード

    マーケティング計画¶

    • SEO: 「請求書 催促 メール テンプレート」「フリーランス 未入金 対処」等の記事
    • Twitter/X: フリーランスコミュニティに「催促が苦手な人向け」として訴求
    • note/Zenn: 「フリーランス1年目が知るべきお金の管理」記事でツール紹介
    • フリーランスSlack/Discord: コミュニティでの口コミ
    • Product Hunt: ローンチ

    技術スタック¶

    • フロント: Next.js (App Router) + Tailwind CSS
    • ホスティング: Vercel (Hobby)
    • 認証/DB: Supabase
    • バッチ処理: AWS Lambda + EventBridge Scheduler
    • メール送信: Amazon SES
    • 通知: Slack Webhook

    リスクと対策¶

    リスク 対策
    催促メールがスパム判定 SPF/DKIM設定。ユーザー自身のドメインからの送信オプション
    取引先との関係悪化を懸念 催促文面を「丁寧・ビジネスライク」に統一。送信前にプレビュー機能
    freee/MoneyForwardとの競合 会計ソフトは大きすぎる。「催促だけ」に特化した軽量ツールが差別化
    個人情報管理 取引先メールの暗号化保存。GDPR対応のデータ削除機能

    競合分析¶

    サービス 違い
    freee/MoneyForward 会計ソフト全般。月額$20+。請求書催促は付帯機能で弱い
    Misoca 請求書作成がメイン。自動催促機能なし
    手動管理（Excel） 忘れる。催促のタイミングを逃す

    差別化: 「請求書催促」だけに特化。会計ソフト不要。登録30秒、自動催促。

    $20達成シナリオ¶

    • Proプラン($4) × 5人 = $20/月
    • フリーランスが月5-10件の請求書を管理するユースケース
    • 1件でも未回収を防げれば月$4は安い（ROI 100倍以上）
    • Free→Pro転換率20%想定で、Free 25人 → Pro 5人
    • SEO + フリーランスコミュニティで月20サインアップ → 2ヶ月で達成
